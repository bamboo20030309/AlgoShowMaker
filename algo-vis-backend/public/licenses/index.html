第三方授權

AlgoShowMaker 使用以下開放原始碼套件。各套件的版權、授權條款與免責聲明均保留於下方，與 AlgoShowMaker 自身的 MIT 授權分別適用。

前端主要使用 Ace Editor（BSD-3-Clause）、Fabric.js、Reveal.js、KaTeX（MIT），以及 iro.js（MPL-2.0）；Reveal 的程式碼反白另外包含 highlight.js（BSD-3-Clause），iro.js 另含 iro-core（MPL-2.0）與 Preact（MIT）。

MPL 套件原始碼

本站使用 npm 發布的原版 iro.js 5.5.2 與 iro-core 1.2.1，未修改套件程式碼。可從以下固定版本提交取得可修改的原始碼；相應 MPL-2.0 完整條款亦附於下方套件項目。

  • iro.js 5.5.2 原始碼
  • iro-core 1.2.1 原始碼

來源註記：iro.js 的 npm 5.5.2 發布資料指向上述提交，但該提交的 package.json 仍標為 5.5.1；此連結依發布者記錄的 gitHead 提供，並保留這項上游版本標記差異。

完整套件聲明

展開套件可讀取授權原文。本清單也涵蓋鎖檔中的間接依賴、開發工具與可選依賴；列出不表示每個環境均會安裝或傳送所有套件。作業系統、Node.js、編譯器與資料庫的授權另隨其發行套件提供。
