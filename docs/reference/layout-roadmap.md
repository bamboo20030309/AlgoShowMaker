# `@layout` 版面配置實作狀態

本文件供開發與教材製作參考，說明排版能力與尚未實作的方向；不是程式執行時載入的設定檔。完整語法以 [指令手冊](algorithm-visualization-directives.md) 為準。

## 已實作：具名遞迴排版

可將遞迴過程保留的畫面自動排列成樹，不必逐個指定座標。例如：

```cpp
// @layout recursion as "quick_tree" at canvas.top offset(0,80)
// @layout quick_tree direction top-down
// @frame arr in quick_tree
// @keep last as "partition" in quick_tree
```

系統記錄每次遞迴呼叫、父呼叫、兄弟節點順序與根節點順序。`@frame ... in` 先使用目前呼叫對應的節點，`@keep` 再將其保存為歷史快照。排版使用 SVG 的實際量測範圍，完成後才處理相對文字、語意箭頭、鏡頭與縮圖，避免各自猜測尺寸造成偏移。

支援 `direction`、`mode`／`order`、`align`、`sibling-gap`、`level-gap`、`degree`、`edges` 與 `reset`。每行設定必須寫出目標 layout 名稱。

樹邊預設為黑色、2px。由上往下的排版，連接父節點外框底部與子節點外框頂部；其他方向使用相對應的外框錨點。

## 已實作：線性歷史排版

`@layout linear` 可將合併排序各輪結果等歷史畫面排成一列或一欄，搭配方向、間距與對齊設定，避免手動計算每個 keep 的位置。這類線性排版與遞迴樹排版不同，應依教學關係選用。

## 定位優先順序

同一物件有多種定位來源時，依序採用：

1. Trace Studio 對該幀快照的明確位置。
2. `@keep ... at` 指定的位置。
3. 所屬具名排版的計算結果。
4. 一般 keep 的自動堆疊位置。

虛擬目標 `keep` 表示目前可見歷史快照的聯集範圍，不包含歷史箭頭與隱藏快照，可獨立用於相對定位。

## 尚未實作的通用約束

以下是後續設計方向，不能當成已支援的指令使用：

- 對任意種類的即時物件提供一致、持續生效的約束系統，而不只使用現有 layout 綁定。
- 分別控制水平與垂直關係，例如「水平方向對齊畫布中心，同時位於 keep 下方」。
- 多個具名 layout 之間的碰撞避免與跨排版箭頭繞線。
- 任意物件共用的排版重設契約。

需先確認樹、圖及其他結構的共同需求，再擴充上述語法，避免為個別範例加入不一致的特例。
