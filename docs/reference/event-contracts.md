# 事件與動畫固定規格

更新：2026-11-09。依使用者確認恢復舊版作用時間，保留新版事件順序與狀態提交，並依來源可見性合併宣告初始化；事件值與指標綁定改由共用執行狀態查詢。本文件描述目標規格；是否已由目前程式通過，必須另外查看驗證報告。列出案例不代表測過，更不代表全部通過。

## 單一事件流程

程式在後端執行一次，Trace 保存實際事件、來源、目標、前後值、執行順序與選中的分支。播放不重新執行 C++，也不從相同數值猜來源。前端依顯示綁定產生動作計畫，再由排程器統一管理開始、完成、提交與清理。

基本視覺動作有六類：入場／退場、複製、搬移、強調、顯示提示、鏡頭移動。物件建立、定位、排版、狀態提交、快照保存與清理屬於內部操作。內部操作不能偷偷提前換值。

每個計畫遵循「準備 → 播放 → 提交 → 收尾」。同一事件中沒有相依的動作可以同步；不同事件預設依實際執行順序。資料、程式行與運算的身分不依演算法名稱、變數名稱或教材幀號判定。

## 事件狀態與畫面投影（2026-11-09）

- `createExecutionContext` 依事件順序與 mutation 建立事件前／後狀態；指標位置、複合索引、比較跟隨、賦值與讀取來源、選值比較、序列操作、位元效果共用此入口。
- 未在這段事件中改變的值可沿用 capture 基準；有變動的值必須先使用第一個 mutation 的 before，再依事件提交 after。不得把其他變數的幀末值混進 `i+k` 等運算式。
- 比較時查詢當下的格子與指標綁定。容器 alias 依 runtime identity、lifetime 與索引辨識；不能以 SVG 節點相同或互相包含來判斷。
- 指標運算式依其綁定的宣告 ID 取得事件當下值；其他函式已退場的同名參數不能覆蓋它。遞迴傳入新值後，保留角色連續性的指標移至該值對應的節點，不先移到未定位停放區。固定案例見 `recursive-parameter-pointer.browser.test.js`。
- 陣列的格子存在與長度也是狀態，`size()` 不得提前看見尚未插入的格子。字串單格寫入只更新該字元，不替換整串字串。
- `@exit` 只控制畫面；scope-exit 才結束 C++ 變數的邏輯存在。停用動畫的事件仍按順序提交狀態，明確抑制的迴圈邊界依既有規格處理。
- 幀末 DOM、版面與交換節點映射僅作為呈現投影，不能當作事件值或指標指向的來源。camera／keep 仍依幀與快照語意處理；作者指令的事件跟隨規則見下節。
- 舊格式序列缺少完整 payload 時，只在前後大小吻合且該容器恰有一次 mutation 時沿用唯一的前後快照；多次 mutation 不從幀末陣列猜中間狀態。

## 作者指令依賴跟隨（2026-11-11）

- `@text` 的運算式、`@let` 別名與 `when` 使用共用事件前／後狀態；在依賴變數的提交點換字並重算文字框寬度與相對定位。條件由假變真時用220ms入場；旁白仍使用幀末內容。
- `@arrow` 的動態索引在對應事件的位移階段起點開始，使用520ms移至新目標；多次更新分段處理，停用的事件直接提交。端點幾何每tick讀實際SVG，不能先採用幀末目標；固定端點與遞迴樹生長時鐘保留。
- style採C2：只有索引／範圍含執行變數的選取跟隨提交；固定索引維持幀語意。只重算依賴的選取，不在每次事件重跑全部繪圖指令。
- 缺少可核實的事件前後值時退回幀末顯示，並在除錯紀錄提示重新RUN。跳幀、反向與穩定渲染直接顯示目的幀，不猜中間值。
- 程式碼面板捲動以邏輯時間驅動CSS動畫，支援倍速、暫停與取消；不再以獨立setTimeout決定結束。
- 同格多欄位各自更新與提交，依原hide／format規則顯示；隱藏欄位仍保留重播目標，分隔符只出現在可見欄位之間。欄位tspan不得被抽離text父層或因比較重新排列。

實際時間為基本時間除以播放倍率。修改倍率在下一事件生效。同一組同步搬移共用時間，不因距離各自提早提交。事件之間沒有額外自動等待；明確的使用者控制值仍需尊重。

一般純量與指標恢復改版前的入場路徑：220 ms 內由上方 16px 回到定位點；指標退場向上移動 16px。文字、陣列容器及 keep 快照沿用各自原有的原地淡入淡出，不套用這個位移。交換與指標移動使用傳入的位移時間，預設 520 ms；動作計畫也使用相同時間，不能另寫固定值。

### 初始化依值來源決定呈現

宣告與初始化賦值仍是兩個語意事件，但只有解析器確認的同一 declarator／執行 lifetime 才可合併成一個播放 slot。`int a; a=b;` 不合併。任一事件被明確關閉時，不用合併重新啟用它；剩餘事件維持自己的設定。

| 情境 | 固定呈現 |
| --- | --- |
| 純常數 `int a=5`、常數陣列 `{1,2,3}` | 完整內容直接入場 220 ms，不再播放一次額外賦值 |
| 所有值來源均未顯示 | 帶著結果直接入場；不額外建立來源物件或浮動算式框 |
| 至少一個值來源可見 | 空目標入場後接既有複製／計算動畫，合成一個連續操作；不可見的部分沿用既有接收格子的數值呈現 |
| `vector<int> num(n,0)` 等數量／填值建構 | 完整陣列直接入場，不強調 n、不繪製尺寸來源箭頭 |
| 指標由常數／不可見來源初始化 | 直接在正確位置入場，不先移到第 0 格 |
| 指標由可見來源初始化 | 和常數／不可見來源一樣，直接在初始化後指向的格子旁入場；不先顯示未綁定標籤或補播跨格移動。宣告與初始賦值的底層資料仍保留，之後的重新賦值照常位移 |
| 既有指標重新賦值 | 保留賦值與 520 ms 位移階段；不能在位移開始前先跳到終點。同值仍播放賦值提示 |

「可見」使用該來源的實際畫面綁定及隱藏狀態判斷，不因變數存在於 Trace 就假定它已畫出。新舊 Trace 共用同一路徑，資料缺少新的非必要欄位不得改變既有明確關閉設定。

初始化 slot 與下一個操作之間同樣套用事件間隔。缺少 `gapMs` 的新舊資料使用 500ms；明確的 `0` 或其他自訂數值保留。編輯器、播放器及播放時間估計共用解析規則，不能在正式載入時把未設定當成零間隔。測試須經動畫載入入口核對缺欄位情境，不能只先填入 500ms 再驗證。

格子放大、縮小與移動時，背景、focus、highlight、point、mark 等格子 style 必須跟隨同一個完整變換。自我比較、整格複製或陣列入場建立臨時格子時，也須攜帶來源的局部 style；不能只複製框與數字，留下 style 停在原處。style 的暫時複本隨格子清理，不增加正式選取或定位物件。

依2026-11-11使用者確認，事件中的格子縮放只改變幾何尺寸，格內數字／索引文字維持原有字級與字形比例，位置仍隨格子移動；不得跟著寬、高分別拉伸。此規則包含整格賦值／插入的飛行副本、一般比較、keep來源比較、heap交換版面縮放及遞迴節點暫時縮放。父子縮放須合成補償，複製時不能把來源暫時的反向縮放帶進新副本；結束或取消須還原文字原有transform。鏡頭縮放與已儲存物件的基準縮放不屬於此暫時事件補償。驗證入口為cell-text-scale.browser.test.js。

格子提升到動畫前景時，附屬 style 也要畫在格子上方，不能留在較後面的快照層而被白色格子蓋住。完成或取消後恢復原本層級與順序。驗證除了座標，還須在抬起及縮放時檢查實際筆畫可見；CSS 的 display／visibility 正常不代表沒有被其他物件遮擋。

### 巢狀運算式

內嵌操作使用相同事件種類，不因位於參數、索引、初始化、條件、return 或另一個賦值內就略過。事件依實際執行完成順序記錄，保留每層的原始來源範圍；不得重跑運算來取得動畫資料。

| 操作 | 固定答案 |
| --- | --- |
| `out.push_back(num[j++])`，j=0、num=[7,9] | 取 num[0]=7，push 結果為 [7]。原始 Trace 保留 write→push 完成；動畫先複製舊索引的格子，再經事件間隔播放 j 的 0→1。來源索引必須是 0，不可用更新後的 1 |
| `a=(b+=3)`，a=0、b=0 | 先 b 的複合賦值 0→3，再 a 的賦值 0→3；兩層都存在 |
| `num[i++]=(c=5)`，i=0 | 先 c=5，再 i 的 0→1，再 num[0]=5；i 不得因定位與提交重複求值而變成 2 |
| `false && (++a>0)`／`true || (++a>0)` | a 不變，不得記錄或播放未執行分支中的 ++a |
| `sizeof(i++)`／`decltype(++i)` | 未求值內容不產生更新事件，i 不變 |

`tests/nested-expressions.integration.test.js` 使用手寫數值／順序核對；`tests/nested-pointer.browser.test.js` 核對重新編譯的合併排序第 12 幀實際 SVG 位移與來源維持。既有 Trace 缺少子事件時須重新 RUN，不能靠最終幀的差值捏造事件。

後置 `x++`／`x--` 的舊值使用與更新動畫分開排程；前置 `++x`／`--x` 仍先更新再使用。其他賦值、複合賦值不套用延後規則。逗點、短路、三元條件及下一操作已讀取新值時，不跨越必要的求值邊界；原始事件序號與 C++ 狀態不改寫。排程、值提交、指標位移與程式反白共用同一播放順序，相關固定答案見 `tests/postfix-presentation.integration.test.js`。舊 Trace 資料不足以判斷複雜邊界時，除錯紀錄提示重新 RUN，不猜測順序。

normal 中間插入及 push_back：0～300 ms 擴框（中間插入同時挪位），300～520 ms 新格子與 index 入場，外框保持最終大小。erase 及 pop_back：0～220 ms 格子與 index 退場，外框保持原尺寸；220～520 ms 補位與縮框同步。尾端操作省略不需要的格子挪位，但保留同一階段順序。resize、clear、整體 assign 保留各自規則。

## 新格子與數字同步入場（2026-11-04）

insert／push_back 的入場階段須同時呈現格子與數字。可見來源使用原有整格複本；常數與隱藏來源在目的位置顯示帶數字的暫時格子，兩者一起淡入。正式 replay 值及 presence 仍等事件完成才提交，提交時接手正式格子、移除暫時呈現，不把數字延遲到提交瞬間才顯示。index 沿用同一入場進度。resize 新增格子也使用帶數字的入場呈現。

## 隱藏程式碼的畫面生命週期（2026-11-04）

@code hide 繼續抑制區段的執行事件。若同一生命週期、已可見序列的前後幀可確認只有尾端新增或刪除（保留的前綴資料相同），播放器產生暫時的 visual-insert／visual-remove 排程，沿用先擴框再入場、先退場再縮框的規則。這不是推定原本呼叫 push_back／pop_back，不產生可儲存的假執行事件。已有操作事件（包含明確關閉的事件）及不同遞迴生命週期不使用此補排程。無法由已儲存資料確定的中間變化不猜造來源或操作。

## render 的生命週期分工（2026-11-04）

無 runtime 事件的尾端增減補排程目前只作用於 render normal。disk 的圓盤由連續身分追蹤跨柱位置，不能套用一般陣列的新格入場／退場遮罩；heap 等其他 renderer 也保留既有幾何規則。暫時視覺補排程在 frame handoff 的前段執行，不排在後續 output／call 提示之後；原本真實事件之間的執行順序不改變。鏡頭、結構或新節點入場所需的既有 barrier 仍保留。

## 讀取強調預設（2026-11-04）

讀取仍附著於所屬操作，不增加獨立停頓。顯示預設關閉；事件設定面板的「讀取強調」開啟後才建立 highlight，預設顏色為純紅色 red（#ff0000）。設定保存於 studio.eventSettings.readHighlightEnabled（布林值）與 readHighlightColor（預設 red）。缺少欄位的舊資料視為關閉；明確 true／false 與自訂色保留，設定可隨 @asm-view、投影片、Trace 引用與帳號偏好保存。不恢復已移除的逐步讀取事件開關。

## 遞迴節點入場（2026-11-08）

新遞迴節點使用所屬參數或區域變數的宣告事件作為入場時鐘：先反白停留 200ms，再以宣告入場的 220ms 長出完整節點。layout 決定幾何，不另行提前生長。以 activation／變數 ID 綁定事件，舊資料可用 lifetime 核實；關閉宣告動畫時直接到位。格子、名稱、索引、style 與新連線共用此時鐘；父節點重新排版時，生長起點跟著父節點當前位置。keep 交接不重播。純繪圖快照沒有 runtime 宣告時，保留既有 layout 行為，不製造宣告事件。固定答案與實際 SVG 驗證入口為 tests/recursion-declaration-clock.test.js、tests/recursion-declaration-clock.browser.test.js。

## 指標群組排版與事件狀態（2026-11-09）

同格指標的槽位由當下事件狀態計算，不直接套用目的幀的最終成員。宣告／入場、賦值位移、scope-exit／視覺退場都以所屬事件改變群組：舊指標開始淡出時，其他指標才補位；尚未入場的指標不占位。退場與補位共用 220ms，既有一般讓位使用 300ms，指標跨格位移仍沿用事件本身的時間。關閉動畫的事件保留狀態提交，不額外補播入退場。

只改顯示、不改 C++ lifetime 的指標增減，使用暫時的視覺入退場時鐘；不產生持久化的假 runtime 事件。若新指標必須等待舊指標退場，等待期間不預留新指標槽位。離場複本、存續指標與比較跟隨共用同一套位置／箭頭狀態，避免重複疊加舊版重排。矩陣列／欄標籤與二維格子沿用各自的座標鍵，不將缺失二維格子當成一維索引推算。

固定畫面答案見 `tests/pointer-event-reflow.browser.test.js`：快速排序第 18→19 幀在 j 完全可見時 i 的 x 不變，j 淡出時 i 才移動；另查宣告、移動、純顯示移除、矩陣列指標及延後替換入場。取樣實際 SVG 標籤位置與有效透明度，不以播放計畫自身當作標準答案。

## 引用容器的呼叫交接（2026-11-10）

引用參數的宣告不代表建立新的容器。如果前後畫面具有相同 runtime 儲存身分、同一 scene、相同作者別名與 layout 節點，且前一容器仍可見，沿用整體容器及其格子／標籤，不重播宣告入場。此規則適用跨函式、返回呼叫者與遞迴；指標／純量仍按自己的 lifetime 處理，容器延續不能直接當成指標角色延續。

不能只比名稱或物件 ID：不同儲存身分、新的值容器、明確 visual-enter／visual-exit、已結束的擁有者、keep／新 scene、不同別名或新的遞迴 layout 節點，都保留獨立生命週期。缺少新欄位不另加必填資料，沿用既有型別及 runtime metadata。驗證入口為 `reference-container-continuity.test.js`、`heap-reference-continuity.browser.test.js`，另以 `recursion-declaration-clock` 兩檔檢查新節點入場未被抑制。

## 退場箭頭的幾何交接（2026-11-10）

繪製器公布指標的實際端點與錨點模式：固定指向格子，或隨同格標籤的水平位置對齊。退場排程用退出前的成員狀態校正標籤與端點，不能因它已不在目的幀的 finalState，就漏算原本 layout／座標偏移。heap 原本直向的箭頭應在淡出時保持直向；正常陣列仍依原錨點跟隨位移與讓位，不一律凍結所有箭頭。

重新計算箭頭時保留原本連接標籤的邊：上方標籤從底邊出發，矩陣列標籤從右邊出發。前一幀事件提交若已移動指標，完成時同步更新呈現端點，下一幀退場不能讀回較舊的端點。這些都是暫時 DOM／播放器資料，不新增 Trace 必填欄位。固定答案見 `tests/pointer-exit-arrow.browser.test.js`，另以指標重排與模型案例核對既有路徑。

指標退場路徑固定為「從自己退場開始時的位置向正上方淡出」。到達自己的 exitStart 後，不再加入同格成員變更所產生的水平補位；箭頭與標籤作為同一個完整視覺共同向上移動。同批退場共用原有退出時鐘；仍留在畫布的指標才參與補位。退場前的合法賦值／位移不省略，應先完成，再從當時位置退出。此規則同時涵蓋離場副本、當幀 DOM 內的自然退場與 `@exit`／keep 交接。

## 刪除前保留與關閉初始化的入場（2026-11-10）

目的幀已刪除的序列格子，在刪除事件的程式提示及前置事件期間仍須完整保留，直到該事件的視覺退場開始才交接給退場副本。不能在建立目的幀 SVG 時提早消失、等動作開始又出現；取消播放也必須清除保留副本。此規則包含 heap 範圍縮短後已不在目的幀 DOM 的尾端格子。

初始化賦值明確關閉時，不補播該賦值，也不把宣告物件留在空值／未綁定狀態。宣告使用該次執行捕捉的初值入場；指標直接出現在初始化指向的格子旁，之後的合法重新賦值仍依事件狀態位移。例如 `int largest = now;` 初始化到 1，後續 `largest = left` 才移到 2。固定 SVG 驗證入口為 `tests/heap-pop-initializer.browser.test.js`。

序列刪除使指標暫時沒有對應格子時，若相同生命週期的後續 assign／write 在同幀將它移回有效格子，不把這個暫時缺口當作退場。保留原位置到該操作開始，再連續移到新格子並保留至幀結束。例如 heap 刪除第 10 格後，heapSize 等到 `--` 才由 10 移到 9。這份暫時繪圖綁定由 pointer model 按事件順序推導，穩定跳幀與重開同樣適用，不寫回儲存資料。明確 retarget、declare／scope-exit／visual-exit、儲存身分變更，以及最後仍越界的情況不補綁定。

沒有實際目標格子的指標箭頭固定垂直向下。越界索引的外推座標僅供位移定位，不是可瞄準的格子；目標鍵仍由事件位移軌跡取得，不從目的幀 DOM 推測指向。移入實際格子後恢復該格子的正常箭頭定位。此判斷同時傳遞給一般指標及離場副本，不因此更動真實格子的既有矩陣側向箭頭。

同格新增指標，即使從幀內第0毫秒開始，也必須透過共用指標排程加入群組並讓既有標籤補位，不能預先占位或漏掉讓位。第一個非零透明度的畫面就使用事件初始目標，不先在目的幀最終索引閃現。label 錨點模式同時適用存續指標與離場副本，標籤讓位時其直向箭頭一起平移；target 模式保留指向格子中心的原有行為。固定答案見 heap-pointer-peer-entry.browser.test.js。
