# AlgoShowMaker v4.9 — Segment Tree 與穩定播放更新

## 演算法與教學範例

- 重寫完整 Segment Tree 範例，並新增可獨立展示建樹與查詢流程的簡化版本。
- Segment Tree 支援複合欄位、lazy／set 持續背景、操作區間 segment、遞迴拆分交接及具名陣列指標。
- 父節點加總會保留兩個來源操作數並依事件順序播放；舊投影片 trace 會在編輯器自動重建後保存。
- Heap 範例與複合資料繪製、格子尺寸變化及 segment 分層同步更新。

## 播放、標記與時間線

- 上一步與時間線跳轉使用穩定幀重建；動畫中再次按下一步會先穩定目前目的幀，再播放下一段。
- 新增三連點快轉、按住按鈕或方向鍵 repeat，並在分頁隱藏時暫停動畫與 TTS。
- Marker 依宣告順序排列，來源格立即回填、目的格從移動開始讓位，箭頭方向隨跨格移動連續更新。
- Reference parameter alias 跨函式返回時保留 focus 與 fixed mark；heap swap 的新固定標記會在交換完成後顯示。
- 停用、隱藏或無可呈現動畫的事件不再建立時間線標籤。

## 投影片與前端

- 投影片物件框選、結構長度為零、結構設定選單顯示與數學內容載入行為修正。
- KaTeX 改由專案內建資源載入，範例與投影片數學內容可在不依賴外部 CDN 的情況下呈現。
- 更新相關入口快取版本與精確入口測試。

## 驗證與限制

- 三分支整合聯合集合共 16 個測試檔、123 個案例，全部通過。
- Heap 限定動畫回歸通過：algorithm 548、editor 543、runtime 548 個取樣；cloud storage、投影片排序與 deck 匯入修復前置檢查亦通過。
- Segment Tree 三個範例、舊投影片 trace 重建、二元加法、完整背景／segment 連續性、reference alias、fixed mark 與瀏覽器播放導覽專項通過。
- 本次沒有執行所有測試檔或全部演算法的完整動畫矩陣；驗證範圍依實際修改集中於 Segment Tree、Heap、播放器、marker、style 與投影片嵌入。
- Release 不包含資料庫遷移或正式資料寫入驗證。
