# AlgoShowMaker v4.8 — 範例投影片與多代理整合更新

## 公開範例

- 新增快速排序、冒泡排序、選擇排序、插入排序、堆積排序，更新線篩（Linear-Sieve）。
- 六份範例各18張，共108張，包含12張演算法動畫投影片；公開分類為排序與數學，免登入、唯讀觀賞。

## 主要功能與修正

- 個人工作區支援資料夾、多分類、卡片拖曳排序與站內建立／命名／移除對話框。
- 修正文字undo與清單編輯、外部檔案拖入、code關注行對齊與游標閃爍。
- 一般結構支援格子樣式工具列、註標箭頭與選色、預設及各格註標文字。
- 演算法支援每幀@events、@automark、實際／具名迴圈與共用繪圖區塊、批次箭頭、逗號多樣式、文字陣列與切片。
- 修正返回目的幀樣式、事件動畫關閉時的固定／標記狀態及批次箭頭配對位移；文字預設14px。

## 驗證與限制

- 各整合批次依修改範圍執行相關案例，最近自動標記與文字整合49項案例通過，包含實際演算法投影片iframe。
- 本次六份asmdeck格式／版本／內容與素材雜湊驗證、18張唯讀公開載入及每份兩個動畫iframe取得trace通過；格式與入口相關案例通過。
- 未重新執行所有演算法／幀／速度的完整驗證，不宣稱所有動畫或實機操作全面驗收。
- 歷史投影片排序／保存重開曾有間歇失敗；本版專項通過不代表所有歷史情境已結案。未進行真實帳號跨裝置儲存或資料庫遷移驗收。
