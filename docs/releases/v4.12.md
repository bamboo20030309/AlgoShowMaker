# AV_V4.12

2026-10-06。本版改善多人編譯、範例載入與投影片編輯，並修正排序動畫的指標、格子轉移和 keep 行為。

## 主要更新

- 後端加入公平編譯佇列、非同步工作、取消與資源限制，各使用者的結果及除錯訊息獨立。
- 快取編譯產物與 Trace，範例直接載入預建結果；預設線篩使用獨立動畫、首幀預覽與 IndexedDB 快取。
- 改善投影片按需載入、儲存及大型教材編輯效能。
- 統一 Fabric 選取框、混合物件複製貼上、structure／table 格子編輯與選色器；編輯保留縮放、排版及樣式。
- 修正插入排序 j+1 定位、選擇排序指標生命週期與順序、冒泡排序比較方向，以及末幀提前退場。
- int key = arr[i] 複製完整格子與數字到 key，保留來源與自訂樣式，落地清除副本；舊 Trace 可直接套用。
- 改善 keep 快照、合併排序與遞迴排版、賦值提交與格子／索引的顏色同步；LOD 數字門檻為 14px。
- 新增合併排序與八皇后問題教學投影片，更新教材名稱與分類標籤。
- 更新使用與驗證手冊，加入依賴指紋續跑與 20 類固定行為規則；README 保留精簡入門，版本日誌獨立維護。

## 驗證

256／256 個測試檔、20／20 個動畫與 3 個前置契約通過；15 套範例的 36 個動畫實際重載通過，沒有重新編譯。隔離 Linux 的 6 個資源／故障恢復案例全部通過，包含 MLE，沒有略過。已通過且依賴未變的結果沿用，只續跑失敗或失效項目。

詳細證據與測試範圍見 [最終發布驗收](../agent-tasks/2026-10-06-v4.12-release.md)。

## 2026-10-07 補充更新

本次更新 main 的程式與文件，沿用 AV_V4.12；不建立新 tag 或發布新 Release，既有 tag 仍對應原發布提交。

- 正規化 C++ 的 CRLF／CR 換行，讓語法樹、追蹤解析、編譯與編輯器行號使用一致來源。
- 一般執行及解析失敗會清除舊動畫；回傳 Trace 的來源不一致時拒絕套用，避免不同程式沿用上一份動畫。
- 空程式請求與編譯準備例外回傳明確錯誤，後端服務保持存活。
- 展示模式的本機演算法編輯入口後續改為整套範例投影片的本機編輯，詳見下方補充整合。
- 語法樹、分析、編譯、Trace 載入與事件缺少畫面目標的警告集中在「除錯紀錄」。移除強制重編譯按鈕與快捷鍵，保留正常 RUN。
- 製作 skill 優先沿用實際演算法變數與字串陣列、遍歷指標及預設樣式；省略多餘設定，保持後續所需物件在相鄰幀中的連續呈現。
- 修正從隱藏画布的頁籤 RUN 後首幀名稱錯位：略過零尺寸文字量測，切回畫布後校正；首幀、名稱相容性、頁籤鏡頭及入口版本 4 個相關案例通過。
- 繪圖專用邏輯優先用 when、let、for；必要的輔助 C++ 用 code hide 隱藏，事件難以呈現的對應關係可用 arrow 補充。

原 GitHub AV_V4.12 Release 說明同步補充以上內容；最新程式與 skill 從 main 取得，原 v4.12 tag 與其自動來源封裝仍保留原發布提交。

原版上述完整驗收紀錄不代表補充更新重跑了完整 V3。本輪沿用已核實的換行與故障恢復等相關紀錄，並重驗警告位置、解析失敗及 RUN 控制；合併紀錄見 [4.12 補充整合](../agent-tasks/2026-10-07-v4.12-supplement.md)。

## 2026-10-07 補充整合：指標、定位與投影片編輯

本次將已驗證的 intergration 結果合併 main，版本仍為 AV_V4.12。未建立新版本或移動原 tag；更新程式請拉取 main，原 tag 的來源封裝仍是初次發布內容。

- `char(s)` 將原始字串呈現為字元陣列，保留物件名稱、索引標籤及事件來源，不必另建展示用陣列。
- 獨立 `@pointer` 支援二維 row／column／格子定位、顏色與 `i-1` 等運算式標籤，保留原矩陣設定。修正同一變數指向不同陣列時，新指標從錯誤陣列進場的問題。
- `@arrow`、`@place`、`@text` 與 `@camera` 共用索引格子端點描述，可指定 `s[p[j-1]].index-label.bottom`。索引關閉時不會偷偷改用值格；其他子物件與集合定位仍有專屬路徑，並非全部端點已統一。
- structure 的渲染、Fabric 選取框、框選、對齊與格子命中共用主體幾何；point／註標不推移主體選框。補正 disk 完整邊界、縮圖截切與透明邊框偏移，保留縮放及自訂值。
- structure 的預設樣式與動畫一致，預設指標外框及箭頭為黑色；既有自訂顏色保留。
- 幀條首幀與末幀對應左右端點。投影片與排序總覽支援左側縮放、Ctrl＋滾輪及 Ctrl＋加減鍵，各自保留縮放狀態。
- 範例投影片可使用完整編輯器，修改只保存在本機，不回寫公開教材；移除過渡版本的展示程式碼編輯覆蓋介面。
- code 選取框只調整容器邊界，保留字體大小與行距；單獨選取 code 時角落可分別調整寬、高，不鎖定比例。
- 教材 skill 改為精簡入口與分類參考，整理既有指令、focus 表示尚未計算區域，以及 text 自動寬度等製作規則。

## 2026-10-07 補充整合：卡片、封面與分享

本次將 intergration 的 fa62aa8 與先前相關更新合併 main，沿用 AV_V4.12，不新增版本或移動原 tag。

- 工作區 API 一次回傳縮圖、標題、分類、頁數、最後編輯時間與資料夾排序；首頁不讀取完整投影片、素材或 Trace，缺少縮圖時顯示預設封面。
- 15 份公開範例預先保存卡片資訊及縮圖，訪客首頁不再下載、解包所有範例投影片。
- 新匯出的 `.asmdeck` 使用可獨立讀取的 ASMDECK2 封面區，包含縮圖、分類、頁數與編輯時間；首張內容未變時沿用封面快取。舊 ASMDECK1 仍可完整匯入，未知編輯時間保留 null。
- 新匯出只保存動畫 Trace ID，結果以獨立資源按需載入；缺少資源時明確提示重新 RUN。既有內嵌 Trace 的舊檔仍相容，未批次覆蓋公開範例原檔。
- 觀看分享連結可使用完整編輯器，修改及草稿只留在該瀏覽器，不寫回伺服器；分享撤銷仍受權限檢查。移除暫時的工作坊專屬入口。
- 首頁刪除確認視窗將刪除放左側、取消放右側。

相關格式、API、瀏覽器與相容性局部驗證通過，涵蓋舊檔載入、使用、保存重開及既有自訂／關閉值。沿用依賴未變的已通過結果，本輪沒有重跑完整 V3。
