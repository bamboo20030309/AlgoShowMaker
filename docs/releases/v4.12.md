# AV_V4.12

2026-10-06。本版改善多人編譯、範例載入與投影片編輯，並修正排序動畫的指標、格子轉移和 keep 行為。

## 主要更新

- 後端加入公平編譯佇列、非同步工作、取消與資源限制，各使用者的結果及除錯訊息獨立。
- 快取編譯產物與 Trace，範例直接載入預建結果；預設線篩使用獨立動畫、首幀預覽與 IndexedDB 快取。
- 改善投影片按需載入、儲存及大型教材編輯效能。
- 統一 Fabric 選取框、混合物件複製貼上、structure／table 格子編輯與選色器；編輯保留縮放、排版及樣式。
- 修正插入排序 j+1 定位、選擇排序指標生命週期與順序、冒泡排序比較方向，以及末幀提前退場。
- int key = arr[i] 複製完整格子與數字到 key，保留來源與自訂樣式，落地清除副本；舊 Trace 可直接套用。
- 改善 keep 快照、合併排序與遞迴排版、賦值提交與格子／索引的顏色同步；LOD 數字門檻為 14px。
- 新增合併排序與八皇后問題教學投影片，更新教材名稱與分類標籤。
- 更新使用與驗證手冊，加入依賴指紋續跑與 20 類固定行為規則；README 保留精簡入門，版本日誌獨立維護。

## 驗證

256／256 個測試檔、20／20 個動畫與 3 個前置契約通過；15 套範例的 36 個動畫實際重載通過，沒有重新編譯。隔離 Linux 的 6 個資源／故障恢復案例全部通過，包含 MLE，沒有略過。已通過且依賴未變的結果沿用，只續跑失敗或失效項目。

詳細證據與測試範圍見 [最終發布驗收](../agent-tasks/2026-10-06-v4.12-release.md)。

## 更新部署

Node.js 需要 20.19 以上，建議使用 Node.js 22。Docker 部署更新程式碼後需重新建置 backend 映像並重啟 backend／nginx，資料庫及資料卷保留。操作見 [安裝與部署指南](../../SETUP_GUIDE.md)。
