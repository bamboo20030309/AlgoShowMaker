# AlgoShowMaker v4.11 — 教學動畫、事件控制與大型專案效能更新

本次版本補齊遞迴、動態規劃與二維陣列教材，整理動畫事件控制，並改善長時間軸與大型畫布的編輯及播放效能。

## 教學內容與動畫

- 新增前綴和、河內塔、費式數列遞迴與最長共同子序列教學投影片，補強遞迴樹、回傳路徑、回溯與多來源運算動畫。
- 二維陣列支援可調整的呈現方式、二維範圍樣式與多行文字片段，前綴和教材可分步呈現四項矩陣來源。
- 遞迴節點會從父節點展開、在回傳時更新內容，並保持箭頭、鏡頭與節點重排的一致性。
- 算術複合賦值、函式呼叫與流程跳轉的動畫順序更貼近實際執行流程。

## 事件與程式碼呈現

- 連續宣告與初始化會拆成獨立事件；容器建構保留宣告與賦值，不再額外產生不需要的建構函式呼叫事件。
- 將 assign／write 統整為「賦值」，return／break／continue 統整為「流程跳轉」，物件與手動退場共用「退場」設定；「讀取」從使用者事件設定移除。
- 事件設定依教學流程重新排序，並保留底層事件型別及舊資料相容性。
- `@` 指令建議會依目前行內容過濾；輸入其他按鍵時關閉，下移選取時清單會同步捲動。
- Trace Studio 可逐幀調整程式碼片段，並可讓同一來源指令的選擇共用到相關幀。

## 投影片與互動

- 展示模式拖動畫面或使用滾輪縮放後，鏡頭位置會保存到投影片；相對配置與明確錨點在拖曳後仍保持正確。
- 投影片刪除改用專案內的確認視窗；結構物件可編輯外框名稱、以格子作為拖曳把手，文字物件預設依內容調整寬度。
- LaTeX、舊動畫與既有投影片物件持續支援載入、使用、儲存與重開。
- 播放器顯示依實際播放校正的時間估計，並使用精簡的單一時間軸控制。

## 效能

- Trace Studio 僅建立可見範圍附近的幀卡片與縮圖，並延後未瀏覽幀的可用性檢查。
- 演算法畫布略過視窗外物件與儲存格的繪製，移動鏡頭後會正確恢復內容。
- 大型時間軸、500 幀 Studio 與大量縮圖更新維持有限的 DOM 與渲染工作量。
