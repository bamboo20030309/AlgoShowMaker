# AlgoShowMaker v4.11 — 大型動畫效能、教學內容與播放體驗更新

v4.11 讓大型演算法動畫更快進入畫布、縮放與瀏覽，同時補齊遞迴、動態規劃和二維陣列教材，並整理動畫事件與播放控制。

## 大型動畫與 Trace Studio 效能

- RUN 完成後直接留在動畫畫布，需要時再開啟 Trace Studio，避免大型專案先建立整套 Studio 介面。
- 畫布重用穩定的場景結構，縮圖也沿用既有幾何；切換幀時減少大量 SVG 節點重建。
- Trace Studio 只建立目前可見區域附近的幀卡片與縮圖，畫布也會略過視窗外的物件和儲存格。
- 大型陣列與矩陣依縮放比例切換細節：遠景保留結構和樣式，靠近後才建立可讀文字；平移或放大會自動補上進入視窗的內容。
- 數字及文字寬度量測加入快取，重複值、字型與版面不再反覆計算。
- Trace 檔案改用分塊、去重與 gzip 儲存，可直接讀取所需區塊；損毀或超出限制的資料會明確拒絕，不會靜默缺幀。
- 動畫只保留實際 `@frame` 之間會播放的事件，忽略第一幀以前與最後一幀以後無法呈現的追蹤資料。
- 開啟再關閉 Trace Studio 後，畫布會保留目前縮放細節，不會突然重建所有文字或重播事件。

## 教學動畫與範例投影片

- 新增前綴和、河內塔、費式數列遞迴與最長共同子序列教學投影片。
- 遞迴節點會由父節點展開，回傳時更新內容，並維持箭頭、鏡頭與節點重排的一致性。
- 二維陣列支援範圍樣式、多來源算式與自訂列／欄標籤，前綴和教材可逐步呈現四項來源。
- 連續宣告與初始化會拆成獨立事件；容器建構保留宣告與賦值，不再產生不需要的內層建構呼叫動畫。
- 算術複合賦值、函式呼叫、遞迴角色與流程跳轉的動畫順序更接近程式實際執行。

## 事件、程式碼與播放控制

- 將 assign／write 統整為「賦值」，return／break／continue 統整為「流程跳轉」，物件退場與手動退場共用「退場」設定。
- 移除不需要的「讀取」事件控制，事件選項依教學流程重新排序；舊投影片中的事件型別與明確關閉設定仍會保留。
- `@` 指令建議會依目前行內容過濾，輸入其他按鍵時關閉，使用方向鍵移動時清單會同步捲動。
- Trace Studio 可逐幀選擇程式碼片段，也能將同一來源指令的片段設定共用到相關幀。
- 播放器使用精簡的單一時間軸，並依實際播放速度顯示校正後的時間估計。

## 投影片與畫布操作

- 展示模式拖曳或滾輪縮放後會保存投影片鏡頭，重新開啟與切換編輯／展示模式後仍保持位置。
- 右鍵物件選單與「顯示完整屬性」介面已移除；在空白處或動畫物件上按住右鍵即可平移動畫畫布。
- 投影片刪除使用專案內確認視窗；結構物件可編輯外框名稱並直接拖曳格子。
- 文字物件預設依內容調整寬度，LaTeX、行內上下標、舊動畫與既有投影片物件仍可載入、儲存及重開。

## 驗證

- 完整發布基準：160 個測試檔、621 項自動化測試全部通過；16 個動畫／前置項目完成。
- 三介面動畫驗證共 42 組結果、14,980 筆取樣全部通過，涵蓋演算法頁、投影片編輯器與投影片執行環境。

- 大型場景驗證涵蓋 3,000 格結構與 11,000 格棋盤、可見文字細節、縮圖幾何重用、Trace 分塊、事件順序及 Studio 三次開關。
- 相容性驗證涵蓋舊版 Trace、缺少新欄位、明確 `false`／`0`、自訂顏色、儲存後重開，以及右鍵畫布平移。

驗證使用隔離的本機服務與瀏覽器，沒有操作使用者投影片；正式環境資料庫與公開站台部署會在發布後另行核實。
