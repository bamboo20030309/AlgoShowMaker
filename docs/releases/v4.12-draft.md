# AV_V4.12 發布草稿

更新：2026-10-06。程式候選：intergration `3920e5c`；上一穩定版本：AV_V4.11，main `9ddf399`。正式發布日期、tag 與合併提交尚未建立。以下內容可作為 GitHub Release 說明，驗收狀態保留在文件中。

## 主要更新

### 多人使用與載入效能

- 加入公平編譯佇列、非同步工作、資源限制與取消處理，隔離各使用者的執行及除錯訊息。
- 快取編譯產物與 Trace，範例使用預建結果，減少重複編譯。
- 預設線篩改為獨立動畫，支援首幀預覽、背景載入完整動畫及 IndexedDB 快取。
- 投影片按需載入動畫資料，改善儲存與編輯大型教材時的負擔。

### 投影片編輯與教材

- 統一不同物件的選取、Fabric 選取框、混合物件複製貼上及樣式保留。
- 改善 structure／table 格子切換、直接輸入、範圍與多格選取；編輯時保留物件縮放。
- 統一選色器：一般屬性顯示目前顏色，style 按類別記住上次選色，常用色以色塊呈現。
- 數字細節的 LOD 顯示門檻調整為 14px。
- 新增合併排序與八皇后問題範例投影片，更新教材及分類標籤。

### 動畫正確性與相容性

- 修正插入排序 `j+1` 的數值解算與移動定位。
- `int key = arr[i]` 複製完整來源格子與數字到 key，保留來源與樣式，落地清除副本；舊 Trace 不必重編譯。
- 修正選擇排序指標的生命週期、排列、重疊與末幀提前退場；依 arr[...] 書寫順序排列指標。
- 修正冒泡排序比較指標的上下方向，避免後續交換改變比較配對。
- 改善 keep 快照、遞迴與合併排序 layout、賦值提交、值格與索引的顏色同步。
- 修正已關閉插入動畫仍淡入、預設動畫覆蓋外部 Trace、遞迴箭頭去重及分頁鏡頭保留等問題。
- 保留舊設定、自訂樣式與明確關閉設定，增加新舊資料及儲存重開驗證。

### 文件與驗證

- 提供驗證集使用手冊、分類索引、依賴指紋續跑與 T01～T20 固定行為規則。
- README 保留功能與快速入門；語法、部署及驗證細節分別放入專用手冊，版本日誌另存 version_log.txt。
