# AV_V4.12 發布候選

狀態：尚未取得完整最終發布驗收，不合併 main 或發布。版本號 v4.12 暫定。候選基準：intergration `0ff4b37` 加上後續 Trace 修復、測試整理與範例 Trace 更新；上一穩定版本：v4.11／main `9ddf399`。

## 主要變更

- 後端加入公平編譯佇列、非同步工作與使用者隔離、資源限制、執行檔／Trace 快取；部署設定支援四核心環境。
- 範例預建 Trace、獨立線篩預設動畫、首幀漸進載入與 IndexedDB 快取，降低重複編譯及載入成本。
- 統一投影片物件選取、格子編輯與貼上、顏色記憶、混合物件複製、Fabric 選取框，以及舊物件相容處理。
- 改善 keep 快照、遞迴／合併排序 layout、數值提交時機與棋盤動畫；LOD 數字細節門檻為 14px。
- 修正插入排序等複合索引指標的數值型別：動畫中的 j+1 不再把 1 與 1 拼接成 11；新舊 Trace、前進／倒退與保存重開局部驗收通過。此修正後完整 V3 的證據仍待依指紋續跑。
- 新增合併排序與八皇后正式教學投影片，更新範例名稱及標籤。
- 驗證集加入依賴指紋、20 個動畫代表案例、正式教材契約、故障恢復及資源趨勢檢查，並提供驗證使用手冊。
