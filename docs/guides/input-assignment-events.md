# 輸入賦值事件

成功把輸入寫進受追蹤變數時，產生獨立的 `input-assign`，介面名稱為「輸入賦值事件」。沿用一般賦值的動畫、程式碼反白、舊值保持與落定提交；輸入值屬於畫布外來源，通常由目標上方落入。開關與一般賦值獨立，關閉動畫仍保留資料更新。

## 支援寫法

| 寫法 | 處理方式 |
|---|---|
| `cin >> x >> a[i]` | 每個成功擷取的目標各一個事件，保留索引與先後順序 |
| `while (cin >> x)` | 在條件中的成功擷取同樣記錄，EOF不新增成功輸入事件 |
| `scanf("%d %d", &x, &y)` | 按成功轉換數記錄，不把失敗的後續目標當作已賦值；支援抑制轉換與格式寬度 |
| `fscanf`、`sscanf` | 使用相同轉換順位處理 |
| `getline(cin, s)` | 整行字串作為一次輸入賦值；保留可選分隔字元 |
| `cin.get(c)` | 字元輸入成功後記錄 |
| `c = cin.get()`、`char c = cin.get()` | 接收回傳字元的賦值／初始化記錄為輸入賦值，避免再重複一般賦值 |
| `cin.get(buf, size)`、`cin.getline(buf, size)` | 字元緩衝區更新記錄為一次輸入操作 |

`std::`形式也支援。`cin.get()`若只是讀取並丟棄字元，沒有接收目標，不產生輸入賦值事件。目標及索引只求值一次，像`a[i++]`不重複遞增。

scanf的`%n`是已讀字元計數，本輪不列為輸入值；非標準位置參數格式、無法對應受追蹤變數的任意指標別名不猜造輸入動畫。程式仍依原生C++執行。追蹤不替程式修正緩衝區容量或輸入格式。

## 顯示範例

```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 0;
    // @frame x
    cin >> x;
    // @frame x
}
```

第一幀顯示原值，下一步播放輸入賦值。若輸入已發生在第一個畫面之前，首次穩定顯示仍直接呈現該幀結果。

可在事件設定中單獨關閉，或在對應幀使用：

```cpp
// @events input-assign animate off
```

新設定缺省為開啟；明確關閉會隨投影片及動畫設定保存。舊Trace不會憑幀末值補造輸入事件，需重新RUN產生新記錄；生成指紋已涵蓋插樁器與執行期標頭，舊編譯快取不會當作新結果使用。
