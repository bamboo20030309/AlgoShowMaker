# 投影片展示模式的滑鼠操作

## 一般游標與簡報模式

展示模式預設使用一般游標，可以反白、複製投影片文字。右鍵選單可選「簡報模式」，切換成雷射筆並啟用動畫播放快捷鍵；選「一般游標」即可返回。

簡報模式中，動畫畫布的右鍵保留「下一步」功能；要切回一般游標，可在投影片背景或播放器列按右鍵開啟選單。回到編輯模式或重新整理會關閉簡報模式。

選字使用唯讀文字層，沿用 Fabric 的 SVG 文字位置、字型、縮放與旋轉，不改動原本物件。

## 動畫畫布與滾輪

- 尚未拖曳動畫畫布：滾輪切換投影片，先走垂直頁，再進入下一個水平群組。
- 實際拖曳畫布後：該畫布視為已選取，滾輪以游標位置縮放動畫。
- 原地按住或點擊不算拖曳；小於 4px 的滑鼠抖動不移動畫布、不啟用縮放。
- 切離該投影片、開啟其他動畫或重新整理後，需再次拖曳才啟用該畫布的滾輪縮放。狀態不寫入投影片或雲端。
- 獨立 algorithm.html 維持原本的滾輪縮放。

## 播放快捷鍵

只在「簡報模式」的動畫畫布內生效；一般游標、編輯模式、動畫編輯器與獨立 algorithm.html 不啟用。

| 操作 | 對應現有按鈕 |
| --- | --- |
| 中鍵點一下 | 播放／暫停 |
| 左鍵點一下 | 上一步 |
| 右鍵點一下 | 下一步 |

放開滑鼠即執行，不等待雙擊判斷；沒有雙擊跳到起點／終點的快捷鍵。連按兩下等同操作兩次上一步／下一步。對應按鈕會顯示和實際按壓相同的效果。左右鍵拖曳仍可平移畫布，拖曳放開不會觸發步進。
