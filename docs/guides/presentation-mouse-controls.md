# 投影片展示模式的滑鼠操作

## 動畫畫布與滾輪

- 尚未拖曳動畫畫布：滾輪切換投影片，先走垂直頁，再進入下一個水平群組。
- 實際拖曳畫布後：該畫布視為已選取，滾輪以游標位置縮放動畫。
- 原地按住或點擊不算拖曳；小於 4px 的滑鼠抖動不移動畫布、不啟用縮放。
- 切離該投影片、開啟其他動畫或重新整理後，需再次拖曳才啟用該畫布的滾輪縮放。狀態不寫入投影片或雲端。
- 獨立 algorithm.html 維持原本的滾輪縮放。

## 播放快捷鍵

只在展示模式的動畫畫布內、雷射筆游標啟用時生效；編輯模式、動畫編輯器與獨立 algorithm.html 不啟用。

| 操作 | 對應現有按鈕 |
| --- | --- |
| 中鍵點一下 | 播放／暫停 |
| 左鍵點一下 | 上一步 |
| 左鍵點兩下 | 起點／重來 |
| 右鍵點一下 | 下一步 |
| 右鍵點兩下 | 跳到最後 |

左右鍵單擊保留 320ms 的雙擊辨識時間；雙擊只執行對應的起點／終點按鈕，不先執行一步。左右鍵拖曳仍可平移畫布，拖曳放開不會觸發步進。
