# 指標版面、讓位與生命週期確認表

## 填寫方式

- 「已確認」代表目前已有明確規則，不需要再填。
- 「【待填】」代表會影響實作結果，請在該格最後直接補上答案。
- 案例中的 `i → heap[3]` 表示指標 `i` 指向 `heap[3]`。
- 「同格」表示兩個以上指標同時指向同一個視覺格子，不只代表索引文字相同。
