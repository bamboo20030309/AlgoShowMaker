# Format與數字一起移動

使用者要求signed與其他格式跟隨動畫數字落入。原先多欄位動畫拆開格式前綴，在準備階段把+或=固定於目的格，只讓裸數字移動。現在移除固定前綴，並以完整格式文字測量目的欄位；常數與不可見來源使用目的欄位的既有formatter，可見來源傳遞也不再剝掉格式。分隔欄位的逗號仍獨立處理。

不變更原數值、hide條件、500ms傳遞、舊值保持到提交與前景繪製規則。一般無format的值不受影響；新編譯與既有公開Trace使用同一播放路徑，不需重建Trace或新增儲存欄位。

## 驗證

- formatted-assignment.browser.test.js：1倍／4倍速，固定答案+3、=7、0b101、0xA、true、1.25、25.0%、-2；每種格式都實際出現在可見的傳遞文字中，且沒有固定prefix節點。
- multi-field-replay.browser.test.js：線段樹第24→25幀的新編譯與既有Trace；完整+3對準整段欄位中心，舊值2保留到5落定；另驗證=7與負值-2、隱藏與欄位清理、儲存重開、1倍／4倍速。永久分隔符的合法性與準備用臨時逗號分開核對，避免把騰位期間的臨時符號誤判為永久殘留。
- constant-assignment-drop.browser.test.js：一般與複合賦值、常數與不可見來源，以及舊值提交規則通過。

僅V2相關驗證，未跑大型回歸。快取版本tween trace-343、slides-346、runtime-101；推送intergration後重啟3100，不改main或Release。
