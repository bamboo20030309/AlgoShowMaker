# 下落數字的可見性

使用者回報同一線段樹第24→25幀的數字未落定就消失。本輪先核對實際截圖、逐tick座標與交接：隔離環境當次未重現時間上的空白，副本已到基線才由正式文字接手，因此沒有任意延長事件或更改提交時間。

進一步找到共用前景層的確定缺口：傳遞副本先加入動畫層後，若目的格子才被提升，格子會追加在副本後面，其不透明背景可以遮住仍在下落的數字。原本的座標與opacity檢查無法捕捉這種遮擋。現在每次同步皆把暫時事件圖形維持在已提升格子的上方；清理時仍還原原有圖形位置。沒有變更Trace內容或後端指紋。
