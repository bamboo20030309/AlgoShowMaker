# 堆積排序程式碼與 Trace 更新

## 更新內容

依使用者貼上的完整程式碼，更新堆積排序投影片的兩個動畫，程式碼字串（含 CRLF）與附件逐字相同；保留原本兩組輸入及其他投影片內容。依新來源重新分析 watches，避免沿用舊原始碼位移的變數 ID。

新來源使用 `@default` 的 focus arr／zoom(1.6)，因此移除兩個動畫舊的 13 條手動 cameraRules，避免覆蓋新指令；原事件開關、事件設定、字體及其他樣式設定保留。`@pointer 1 at arr`、原有文字與指令均照使用者內容保存，未另改文案。
