# 常數賦值呈現規則

## 行為

- 單一常數來源保留上方落入。例如 `a=5` 顯示 `+5` 下落；`a+=2`、`a-=2`、`a*=3`、`a/=3` 分別顯示 `+2`、`-2`、`*3`、`/3`。
- 運算有多個來源時，常數固定顯示在目標格子上方，不跟著其他值飛入或下落；其他可見來源沿用原本的移動動畫。完成運算時仍由原提交時點一次更新目標。
- 運算符號依該常數的四則運算關係；`b-2` 顯示 `-2`，`2-b` 顯示 `2 -`，避免變成負數 2 的誤解。除法同樣保留前後順序。
- 多個常數在上方分開排列，依文字長度預留間距，不受目標格子寬度壓縮到重疊。
- 保留 signed/assign 等既有格式；不在 `=5` 或已帶符號的普通常數前重複加號。普通常數 0 的移動提示顯示 `+0`，提交到 signed 欄位後仍依既有格式顯示 `0`，再執行原來的退場與逗號清理。輸入賦值維持輸入值原樣，不因同樣使用數字來源而額外加號。
- 舊 Trace 的單常數來源可能沒有 literal 欄位，因此以無 variableId 的數字 token 相容識別；不把隱藏變數當成常數。原本隱藏來源的行為不變。
