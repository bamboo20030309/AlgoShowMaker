# 河內塔視覺生命週期與預設工作區修正

日期：2026-11-04；分支 intergration。

## 問題與修改

1. 使用者河內塔的 ans.push_back 位於 @code hide，Trace 沒有該操作事件，原本退回一般入場／外框補間。現在同一物件生命週期的可確認尾端增減會建立暫時視覺排程；先擴框再入場、先退場再縮框，不往儲存 Trace 寫入假執行事件。既有明確關閉事件不被補排程重新啟用。
2. 拖曳幀條原本先恢復舊 FrameSnapshotCache SVG；Trace 播放器已有自己的穩定幀還原。新增播放器識別，只讓傳統腳本使用舊快照；載入 Trace 同步清除傳統箭頭。
3. 獨立頁面的 DOMContentLoaded 原本仍呼叫 reloadAfterRun 載入退休 code_script.js，與非同步預建線篩競爭，可能覆蓋新播放器並帶回兩個舊箭頭。啟動改由預建線篩／嵌入 payload 負責；舊版 RUN 的顯式重新載入入口仍保留。
