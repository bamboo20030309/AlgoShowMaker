# 多欄位入退場的平滑排版

使用者確認新增先騰位、移除先退場再收位、替換原位接手。本輪把原先清理時移除x而瞬間置中的行為，改成可排程的160ms收位。

## 動作與排程

- 新增：160ms準備階段移動原欄位；新逗號在最後100ms淡入，格式文字再沿既有500ms傳遞落入。
- 清零退場：保持原本0的落入、提交與500ms停留，0與逗號同步淡出100ms，再執行160ms close-field-gap。資料提交仍在落定，不推遲到收位。
- 其他被hide隱藏的可見欄位，例如sets回到LM：舊文字與逗號淡出100ms後收位160ms，不播放巨大哨兵值。原本已隱藏的欄位不新增動畫。
- 原位替換：保留60→61的=5覆蓋+3，不新增欄位，也不額外收放。

收位開始時才測量剩餘欄位的自然位置，使用每tick插值移動，不縮放數字。收位完成後清理定位屬性，位置須與當前自然排版一致。eventActionPlan與實際slot同步加入close-field-gap，沒有將排版延伸到下一個事件；只對隱藏欄位退場移除多餘的通用跨格位移等待，避免重複排程。暫停沿用同一邏輯時鐘。

## 驗證

multi-field-replay定向測試通過，共8組來源／情境各1倍及4倍速：新編譯與既有24→25、60→61、64→65、欄位重設與隱藏，以及左側欄位賦值。

新增固定答案：收位160ms期間lazy與逗號已消失；剩餘tree數字到最終中心的距離逐tick單調減少，最後誤差小於0.5世界像素，確保不是瞬移。新逗號必須觀察到0與1之間的透明度。保留原位覆蓋、格式整體移動、0與逗號同步淡出、舊值提交、儲存重開及字級檢查。
