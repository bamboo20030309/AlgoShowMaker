# 幀條首尾端點對齊

## 任務與結果

依使用者要求，以 index / (幀數 − 1) 計算位置；三幀位置為 0%、50%、100%。拖曳與點擊使用最近幀，懸停提示跟隨同一個位置公式。零幀及單幀固定 0%，不產生除零。algorithm.html 與投影片內嵌動畫共用 front.js，更新腳本快取版本。
