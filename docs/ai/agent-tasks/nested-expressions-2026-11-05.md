# 巢狀運算式事件追蹤

## 問題與行為

合併排序第 12 幀的 `merged.push_back(num[j++])` 原先只有容器事件，漏掉內嵌的 j 更新。這不是單一指令特例：原插樁限制大部分寫入須位於 ExpressionStatement 或 for 標頭，其他父節點中的運算可能只執行、不產生事件。

改為遞迴處理已支援事件類型的運算式，不以巢狀深度或父節點是否為獨立敘述決定是否追蹤。涵蓋函式參數、索引、初始化、return、條件分支、逗點運算，以及內嵌賦值、複合賦值、前置／後置遞增遞減、交換及容器操作。每個事件來源增加 expressionPath，記錄外層運算式的原始位置。

## 求值與播放原則

- 運算只執行一次；保留值、參照與 void 回傳，內嵌 insert 的迭代器不丟失。
- 賦值保留 C++17 右側先求值、再定位左側的規則；帶副作用的左側索引只定位一次。二維索引保存實際列、欄。
- 來源索引在真正取值時保存，不能在事件完成後重跑索引或從最終狀態猜測。索引內的子事件先發生，取值完成才記錄陣列讀取。
- `&&`、`||` 與三元運算的未選分支不執行、不記錄；sizeof／decltype 等未求值內容維持原始碼，不插入 runtime 追蹤。
- 保留既有事件開關與播放時間。實際執行順序決定事件順序：`push_back(num[j++])` 的 j 更新先於 push 完成，與 `push_back(num[j]); j++;` 不同。播放器仍須保留消費該來源的操作所需畫面，不能因最終索引出界提早移除。
- 這是現有 C++ 解析器及受追蹤型別範圍內的巢狀化，不代表已完整支援任意 C++ 型別、自訂運算子或不明別名定位。未定義行為也沒有唯一可驗證順序。
