# 恢復舊版事件節奏，保留新版排程

## 已確認的行為

使用者採用比較報告建議，基準為事件系統改版前 504d51c。只恢復作用時間與指定的比較動作，不退回舊事件身分、狀態重播、逗點指令、讀取強調及跨幀間隔實作。

| 操作 | 新的 1 倍速規格 |
| --- | --- |
| 比較 | 進場 180、觀察 400、動作 300、結果 420、復原 260，共 1560 ms |
| 一般賦值 | 準備 160、飛入 500、完成停留 500、收尾 100，共 1260 ms；第 660 ms 抵達提交 |
| 指標賦值 | 準備 160、來源停留 500、飛入 500、完成停留 500、收尾 100，共 1760 ms；第 1160 ms 提交，之後移位 520 ms |
| 入場／退場 | 220 ms；宣告初始化仍分兩個事件，一般初始化第 880 ms 提交 |
| 交換／指標位移／鏡頭 | 預設 520 ms；自訂鏡頭及明確 0 保留 |
| 陣列插入／刪除 | 保留 300 ms 擴框／挪位，再 220 ms 入場；先 220 ms 退場，再 300 ms 縮框／補位 |
| 程式碼提示 | 一般 400 ms，return 260 ms |

大小比較保留原欄位，不水平靠近；大者放大上抬、小者縮小下壓，指標跟隨而標籤不縮放。相等比較不上下位移，完整 300 ms 用於靠近，不再分成無動作的對齊半段。結果在第 880 ms 才揭示；大小比較保留來源運算符並附 true／false，相等比較依實際關係顯示 =／≠。同值賦值仍完整播放，讀取預設關閉、開啟預設純紅色；跨幀 gapMs 仍生效。

## 驗證與標準答案

V2 局部驗證，未執行完整 regression 或大規模演算法驗證。手寫 manifest 按新確認時間更新，不從產品計畫反推答案。相關探針同步區分抵達提交與動畫結束。

- event-motion-policy：3 項通過；event-camera-timing：3 項通過，包括自訂與明確 0 ms。
- unresolved-markers 只跑宣告初始化分離與移動中的宣告延續兩項，均通過。
- E02、E03、E05、E07、E09、E17、E19：1 倍／2 倍固定時鐘，在提交前一毫秒與提交時核對實際 SVG 數字、複本、來源與樣式、暫存清理，均通過。
- normal sequence 固定時鐘：實際 runtime 與沒有 operation event 的舊狀態資料，1 倍／2 倍，20 組情境通過。外框與挪位先完成，格子與數字再一起出現；退場後才縮框。
- restored-comparison：<、!=、== 與同格自我比較，新 Trace 與保存重開且缺 semantics 的舊 Trace，1 倍／2 倍共 16 組。核對第 879 ms 無結果、第 880 ms 有結果、完整靠近時間、大小原欄位與上下方向、假條件的原運算符、自訂色、復原與清理；自我比較複本也不得上抬。明確關閉的舊比較事件經保存重開後仍不播放。另用實際播放按鈕驗證 1 倍／2 倍自動播放的 start/end 順序與完成等待。通過。
- bubble-compare-pointer：新／舊 Trace，1 倍／4 倍的實際指標幾何、來源索引與保存重開通過。
- truthy-compare：兩項條件解析與實際結果顯示時刻通過。
- event-gap、read-highlight-defaults、event-playback-control：共 4 項通過，包含同值賦值、初始化時間、純紅與自訂色保留、明確關閉、跨幀間隔與保存重開、暫停續播。
- 固定案例 E15、E16、P02、P03 的資料與實際 SVG 通過；C01、C05、C12 的暫停、下一事件變速及混合可見／隱藏來源提交通過。
- 新比較探針首次遇到測試清理原生 performance.now 屬性不存在，已修正測試清理，沒有放寬動作或時間斷言。
