# 合併排序兩種動畫程式更新

依使用者提供的完整程式更新公開合併排序教材：兩份遞迴動畫使用指定遞迴版（與既有程式相同），兩份倍增動畫改用指定版本，包含獨立 l／r 指標與 push_back(num[l++])／push_back(num[r++])。保留四份原測資、全部頁面排版及靜態解析頁內容。

使用隔離服務執行 prebuild-guest-decks --only merge-sort --rerun，遞迴版各 83 幀、倍增版各 61 幀。四份結果皆為 1～10 遞增，程式碼逐字比對指定內容；倍增版含後置遞增 write 事件及字級 16。原測資、非動畫頁及動畫頁其他屬性均不變。

獨立瀏覽器定點載入各動畫第 1、11、12、26、27 及最後一幀，有實際 SVG、無無效幾何或頁面例外。此輪為內容與關鍵幀驗證，未重跑其他教材或全量動畫驗證。

公開清單已指向新不可變 asmdeck 與四份新 Trace ID，canonical 編製來源同步；舊 ID 與舊資源保留。投影片不內嵌完整 Trace。交付 intergration、重啟 3100，不合併 main 或發布 Release。
