# 既有欄位改寬於落定後騰位

使用者要求後方數字等待動畫數字完全落位才騰位。原先所有欄位變動共用準備階段，會讓既有欄位文字尚未變成新寬度，旁邊數字就提前移開。

現在依實際字形寬度判斷：既有可見欄位的新舊寬度不同時，傳遞目的地採原欄位中心，落入前保持其他文字位置；提交後才用160ms插值移至新排版，使用既有500ms結果停留階段，不延長事件。新增欄位仍先騰位；原位覆蓋與退場後收位維持原流程。全程不改字形比例或Trace格式。

另校正SVG文字錨點使用advance寬度、而getBBox使用字形邊界的差異，避免建立獨立文字片段時出現約0.3px的提前跳動；沒有放寬落定前位置不變的標準。
