# 指標從自己的位置垂直退場

## 修改

依使用者要求，指標與箭頭從各自 exitStart 時的位置整組向正上方淡出。同一批退出沿用相同退出時鐘；不再讓另一個指標先從群組刪除後，將也在退場的指標橫向拉到中心。

指標排程增加暫時 exitStart，標籤與箭頭的位移時鐘最多前進到自己的退場起點；後續由既有 -16px 向上位移及 220ms 淡出處理。先前已發生的賦值／指標位移保留，留下的指標仍正常補位。範圍包括 outgoing ghost 及仍在當幀 DOM 的 scopeExitSlot，並非只修離場副本。

不改 Trace 格式、生成指紋、指標交換路徑或整體播放速度。既有 Trace 使用新版播放器即可生效。
