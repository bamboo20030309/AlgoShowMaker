# 英文檔名、資產命名與舊 worktree 封存

## 使用者要求與範圍

所有程式庫檔名改為英文，文件內容維持中文；將 layout 狀態文件改成中文；刪除合併排序舊草稿／腳本與八皇后舊測試教材；分類 scripts 與技術文件；封存舊 worktree；核對 13 份未引用 Trace，並讓系統範例 Trace 以投影片檔名命名。

本輪維持 intergration 開發，未合併 main 或發布新版本。

## 檔案配置

- guides：部署、繪圖指令速查與驗證操作。
- reference：完整指令手冊、固定行為、結構幾何、指標與排版規格。
- development：驗證設計、負載測試與 Trace 資產規則。
- scripts 分為 build、validation、benchmarks、migrations；同步 npm 入口、相對 require、Python 根目錄與驗證依賴指紋。
- 所有中文檔名改成英文；Euler 範例的非 ASCII 引號也正規化。內容沒有改成英文；layout 文件改寫為中文並區分已實作與規劃中的能力。
- 移除合併排序 3 份草稿／資料及 4 個舊腳本；移除八皇后舊教材與依賴它的 2 個舊建置腳本，Git 追蹤內容仍可由歷史還原，另有 repo 外備份。

八皇后相關驗證改用已發布教材，不再依賴私人舊草稿。公開教材的匯入／匯出驗證改核對現行引用 ID 格式，禁止內嵌 Trace。延遲載入案例保留三幀往返、快取、編輯、undo／redo 與整份正式教材匯入。

原性能案例預期停用自動陳述式動畫，但正式教材的設定與舊草稿不同。第一次與第二次失敗均停在該設定斷言；確認預設後，只在性能測試副本明確關閉 declare／assign／write／compare，維持原本的嚴格事件與時間斷言，沒有修改公開教材、引擎或容許值。

## Trace 核對與命名

唯讀核對 70 份本機可解碼投影片及本機 MongoDB 22 份雲端投影片的引用。13 份舊結果中，8 份仍有引用，5 份在可取得範圍無引用；5 份從公開資產移除，外部留原始備份。未修改雲端資料，也不宣稱涵蓋其他離線部署。

36 份現行結果改名為「投影片檔名－動畫序號」，8 份相容結果放 legacy。index.json 保存 ID 到檔案的映射；44 份結果的 canonical SHA-256 均與原 ID 一致。

前端依索引載入並驗證雜湊，舊索引最多更新重試一次。Express 與 Nginx 支援舊 ID 網址轉址；建置工具更新同名結果時保留前一個 ID 的內容，避免舊投影片失效。投影片仍只保存 ID 與個別顯示設定。

## Worktree 封存

18 個舊 worktree 已先保存共同 Git bundle（完整歷史且 verify 通過）、各工作樹差異、暫存差異、未追蹤檔與本機 .env。唯一仍有修改的舊八皇后分支也完整保留。逐檔備份核對 SHA-256，確認沒有使用中的程序及 HEAD 變更後才移除 checkout；先移除 node_modules junction 本身，沒有刪除其共用目標。

目前只保留 main 與 intergration；18 個原分支未刪除。封存位於 repo 外的 Documents/AlgoShowMaker-worktree-archive/2026-11-01，內附還原說明。本機設定不得上傳 GitHub。

## 驗證與限制

V2（資產定位／載入）加相關 V0 文件與腳本配置檢查；不執行完整 regression、廣泛排序或大型動畫矩陣。

- 44 份 Trace 完整雜湊核對，36 份現行教材的封裝、輸入與來源指紋核對。
- 命名索引、舊 ID 轉址、路徑限制、同名建置保留歷史、舊索引更新邊界。
- 舊 ID 經實際 IndexedDB 保存、重開及自訂／明確關閉顯示設定核對。
- 18 個舊 worktree 的 bundle 與非提交檔案備份驗證。
- 21 個腳本 JS 語法、3 個 Python 語法；320 個 scripts/tests JS 的實際相對 require 經 AST 檢查無失效入口。最初純文字掃描將 fixture 字串誤認為 require，改用 AST 核實，沒有建立假的相依檔。
- Nginx 設定經無對外埠的獨立容器 `nginx -t` 通過，未重啟 main 的公開 Docker。
- 相關 9 個測試檔、20 個具名案例通過；失敗案例修正準備條件後只續跑該檔，不重複累加通過數。
