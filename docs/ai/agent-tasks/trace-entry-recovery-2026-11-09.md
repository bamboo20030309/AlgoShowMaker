# Trace 載入入口與合併排序鏡頭核對

## 變更

- 新增共用 trace-version-check，載入與匯出核對版本；同頁併發請求共用，成功短暫快取 5 秒，失敗不快取。回到投影片頁面強制檢查版本；版本變動時先將動畫標紅，再更新可見播放介面，其他頁面維持延遲載入。
- 編輯器對「舊引用 ID／重建設定存在但結果遺失」自動重建，包含缺少新欄位的舊動畫；全新空白編輯器不自動執行。保留自訂字級、明確關閉的動畫設定及舊 view。
- 匯出前按頁核實所有動畫引用；失敗指出頁碼，不輸出未修復檔案。重新按匯出可清除該次失敗恢復快取並重試。匯出仍只保存引用 ID，不內嵌完整 Trace。
- 編輯器完成 RUN 的提示改為「動畫已更新，尚未套回投影片，請按儲存」，區分執行完成與投影片儲存。
- 新增本機鏡頭偏移提示及重設按鈕，只有偏移非預設值時顯示；僅清除目前介面的本機後偏移，不改投影片、Trace 或其他介面的設定。

## 合併排序實際檢查

- 隔離瀏覽器直接開啟 localhost:3100/slides.html?sample=merge-sort，確認載入最新獨立 pointer 及 num[i++]/num[j++] 原始碼。
- 四個公開動畫各以手動 RUN 的 getCompileConfig 路徑重新執行；所有幀的 state/events/source/camera 與預建結果一致。遞迴版各 83 幀，倍增版各 61 幀。
- 另從第一幀連續播放至第 21 幀核對，不只跳幀。
- 使用者確認遞迴版一般案例「下一步」時裁切。唯讀查看原 Chrome 第 21 幀：SVG 高 631，Trace 主體 top=72.40/bottom=722.50，而畫布可視 top=89/bottom=720；縮放比無偏移的 auto fit 大約 10%。其程式碼與資料均是目前版本。測試重現 110% 本機縮放與位移後裁切，重設目前介面後上下恢復至少 19px 留白。
- 不將這項鏡頭偏移誤判成 Trace 過期，也不因綠點宣稱所有畫面都沒有繪圖問題。綠點代表來源、輸入與引擎版本相符。
- 未改動使用者既有分頁、未重置其暫時鏡頭、未操作其投影片或重新 RUN；實際操作驗證在隔離瀏覽器。
