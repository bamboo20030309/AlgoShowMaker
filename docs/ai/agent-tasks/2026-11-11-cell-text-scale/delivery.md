# 格子尺寸與數字字形分離

## 問題與修改

BIT 線性建樹第9→10幀是整格複製，source cell和BIT目的格寬度不同。舊程式以獨立scaleX／scaleY縮放整個副本，連數字也橫向放大；比較的uniform scale亦會把字級一起變大。依使用者要求，暫時事件縮放只改格子幾何，不改數字字級與字形比例。

共用文字尺寸控制器為每個文字保留原transform，合成父容器及格子的暫時縮放後反向補償；文字位置仍隨格子移動。完整接至整格assignment／sequence副本、一般比較／幀內格子縮放、keep來源比較、heap交換縮放與遞迴退場副本。heap原本的path補償保留，文字改由共用控制器處理。鏡頭及已儲存的物件基準縮放保留。

副本複製前還原來源的暫時文字補償，並保留已解析的字體設定，避免移到不同SVG父層後繼承別的字級。正常結束及取消均釋放控制器並還原原transform；取消同時撤去控制器負責的暫時幾何變換。

不改Trace格式、C++、生成指紋或事件時序，不需要重跑公開Trace。同步獨立頁與投影片runtime／編輯器快取版本。

## 驗證

- 新增cell-text-scale.browser.test.js：公開BIT第9→10幀在1／4倍速，矩形確實發生非等比縮放，數字的世界座標scaleX／scaleY都維持1、字級16px。來源num[8]可因LOD位於畫面外而沒有glyph，測試使用該fixture正常格子的固定16px標準，不把缺少來源文字當成縮放通過。
- 新編譯一般比較及公開Merge Sort的keep比較，1／4倍速確認矩形實際放大超過10%，數字兩軸尺寸仍為1。
- 中途取消後，副本清除、正式數字回復原尺寸。另以父子3×2與0.5×4的巢狀縮放確認矩形為1.5×8、文字仍為1×1；24px自訂字級與原translate(3 1)可原樣複製及還原。
- 新編譯heap交換加版面縮小案例，確認ghost實際有非等比縮放、數字未拉伸。最初fixture交換了目的幀已刪除的節點，swap被可見性判定為instant，未進入待測縮放路徑；改用仍存在的兩個節點，保持必須觀察到縮放及文字的固定要求，沒有放寬答案。該可見性限制與本次字形修正不同，未擴大修改。
- 既有push_back整格複製、binary／compound數字轉移、retained compare、現行initializer-visibility及array／matrix的style-cell-motion通過。

指標數值彈出框也套用相同規則，包含比較的初始定位同步與逐幀更新，以及賦值時的來源數字。新增1／4倍速檢查，確認框確實縮放而數字尺寸不變；首次檢查找出初始定位同步漏接，補齊後重驗通過。

## 既有測試的規格落差

arithmetic-assignment.browser.test.js的第一個舊初始化案例仍要求180ms宣告、300ms獨立賦值；目前已確認的初始化是合併slot，實際1480ms。用修改前c811a49的播放器透過隔離瀏覽器route重驗，同樣在1480 !== 180失敗，確認不是本次縮放回歸。保留舊測試不改答案、不宣稱它通過；本次初始化相容性由現行initializer-visibility測試覆蓋。

合計8個相關測試通過，另1個舊規格案例確認基準也失敗。語法與差異檢查通過，未執行完整V3。test-results、暫存腳本及log不提交。
