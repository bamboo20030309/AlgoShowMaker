# 圖片剪貼簿

- 修正來源：物件識別碼僅可在原分頁使用；圖片複製另帶可還原的圖片物件資料，跨 AlgoShowMaker 分頁保留尺寸、旋轉及設定。
- 圖片優先辨識 PNG 等二進位剪貼簿、檔案清單及單張 HTML 圖片；文字／格子正在輸入時仍可插入圖片物件。一般設定文字欄位維持原生貼上，不挪用文字或混合物件剪貼簿。
- 非二進位網頁圖片先讀成內嵌資料；載入或跨來源限制失敗時明確顯示訊息。沒有主動讀取系統剪貼簿的背景輪詢，只回應貼上事件。
- V1 六個案例通過：原生跨分頁／PNG、HTML、無 MIME 圖片檔案、兩個 AlgoShowMaker 分頁圖片設定及保存重開；富文字、混合物件與 structure 格子貼上保留。語法／差異檢查通過，未跑演算法驗證。
