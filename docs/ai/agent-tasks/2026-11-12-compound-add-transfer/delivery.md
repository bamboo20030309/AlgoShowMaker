# 加法賦值的帶符號增量

使用者澄清+=應讓帶加號的增量落入，=才是一般數值落入。先前將運算符號與format混用，且共享傳遞路徑明確清空operatorPrefix，導致一般+=看不到加號。

現在僅對+=恢復加號前綴；=與一般二元運算不額外加上此符號。沿用format整段移動，signed已有+時不重複增加。來源可見時保持原來源位移，常數與不可見來源維持從上方落入，舊值等落定才提交。其他複合運算的呈現規格本輪不延伸變更。

同時修正單一不可見計算來源未保存source值的回退：若+=保存了有限數值的before／after，以兩者差取得增量，不把after結果當作增量。線段樹第24→25幀由舊值2接收+3，提交5，而非落入+5。已捕捉的實際source優先，不覆寫；不改Trace格式。

## 驗證

- constant-assignment-drop：1／4倍速固定答案，四次來源分別3、+2、7、+7；舊值保持、下落與最終14。
- formatted-assignment：signed格式的+=呈現+3且不得出現++；其餘格式整體移動。
- multi-field-replay：新編譯與既有線段樹Trace第24→25幀，tree落入+3而非+5；lazy的signed仍是+3；保留定位、舊值提交、欄位隱藏與重開驗證。
- arithmetic-assignment選定案例：可見來源result+=b呈現+3，普通四則與其他複合運算維持原固定答案。
