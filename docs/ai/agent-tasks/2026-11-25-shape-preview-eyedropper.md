# 選取形狀預覽與滴管

- 箭頭／線段按鈕隨選取物件顯示頭型、實線／虛線；取消選取恢復新建預設，選取不回寫快取。避免重複替換圖示 DOM，保留按鈕點擊。
- 四套選色器共用滴管：投影片文字／圖形／structure／table、Studio、畫布 GUI 與繪圖工具。取色沿用原控制項的套用、記憶與儲存流程；取消或目標已切換不修改原色。
- HTTPS／localhost 使用瀏覽器原生取色；HTTP 使用頁面內 Canvas、SVG、同來源嵌入頁及純色區塊取色。跨來源、圖片／影片及 CSS 漸層等無法可靠讀取的內容顯示提示，不猜測顏色。不截圖上傳。
- 取色時攔截頁面點擊以保留原選取；Esc 取消。格子懸停選色器在取色期間保持開啟。
- V1 局部瀏覽器驗證 5 案例通過：形狀預覽／快取分離、HTTP 取色與取消、三套控制項套用／切換目標、圖形保存重開、舊 structure 格子保存重開。原生選色視窗以替身測試回傳及取消；實際 OS 視窗待人工操作。語法與差異檢查通過，未跑演算法驗證集。
