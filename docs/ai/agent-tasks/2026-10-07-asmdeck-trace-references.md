# .asmdeck 改為 Trace 引用

## 任務與規格

新匯出的 .asmdeck 只保存動畫原始碼、輸入、Trace ID、顯示設定及投影片內容，不內嵌完整 Trace。Trace 結果獨立存放；開啟封面不下載動畫，進入動畫頁才取得對應結果。匯出引用型投影片也不先取得所有結果。

編輯器產生的 Trace 以內容雜湊 ID 保存到既有本機 Trace 儲存；雲端投影片沿用獨立 Trace API。公開教材可從 public/deck-traces/<ID>.json 讀取。這次工作坊的 13 份結果已拆到該目錄，48 頁檔案由 186644 bytes 降為 63452 bytes。

舊版內嵌 Trace 的檔案仍可匯入，保留顯示設定、明確關閉的事件與自訂值。新匯出禁止完整 Trace／prebuiltTraces。舊歷史範例檔未全部重建，本次先轉換工作坊及更新後續教材建置腳本。

## 找不到 Trace

引用型檔案可以匯入與保存，不因某個 Trace 遺失而阻止整份投影片開啟。動畫頁明確提示重新 RUN，編輯器仍可載入原始碼和輸入。跨電腦使用時必須能存取相同的獨立 Trace 來源，或重新 RUN；ID 本身不是完整結果，也不會自動重新編譯整份教材。

## 驗證

V1：asmdeck 格式／舊檔相容、entrypoints、匯出檔名、workshop-entry 實際瀏覽器驗證。工作坊封面下載 0 份 Trace，第一個動畫下載 1 份，匯出不追加其他 Trace；本機保存、重新整理、缺失 ID 的提示及原始碼編輯均驗證。舊檔測試保留舊格式建構器，不放寬新匯出規格。

首輪有兩個舊格式測試因測試套件的引擎版本格式不符而失敗，修正測試套件後重驗通過；缺失 ID 編輯測試第一次使用錯誤的全域屬性讀取 Ace，改為實際編輯器變數後通過。未修改動畫事件或播放語意，不跑大型動畫驗證集。
