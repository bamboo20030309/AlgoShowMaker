# 事件系統整理與固定答案驗收

日期：2026-11-02。開發與預覽分支：intergration。此次範圍不包含 main 合併、release 或公開主機部署。

## 完成內容

- Trace 記錄實際讀取來源、前後值、選中的分支及語意；同一運算元只在程式實際執行時求值，不重跑有副作用的式子。
- 宣告與初始化分成兩個事件。複製值搬整格，計算新值只搬數字；常數及隱藏來源從目標上方進入，抵達才提交。
- min/max 先比較再賦值，保留實際選中來源；巢狀選值與計算依相依順序安排。相等比較靠近中央顯示 =／≠，不做上下位移。
- 插入先挪位再入場，刪除先退場再補位；resize、clear、move 使用實際前後狀態。交換格子的幾何與狀態共用 400 ms 時鐘。
- 讀取仍有語意紀錄，但 highlight 附著於所屬操作，不閃爍、不新增停頓；同一來源去重，作者手動設定的 highlight 保留。
- 同一變數的指標綁定同步，衍生索引與越界位置由共同規則處理；指標初始化在初始位置入場，不多排一次空移動。
- 暫停保留同一播放工作；恢復、倍率、跳幀、快速連點與離開頁面統一管理。鏡頭先到位，事件預設沒有額外間隔；明確 false／0／自訂值仍保留。
- 修正編譯追蹤中運算元捕捉位置及 C++ 字串輸出，避免來源被結果覆寫；修正 Windows 舊編譯器退出時 thread_local 容器析構問題。

## 驗證與證據

- 固定規格 67 案例：7 份 C++、手寫 manifest 答案，獨立核對資料與實際畫面／控制。
- 其中 10 條核心賦值案例有 1 倍與 2 倍速的固定時鐘探針，核對提交前後、複本、來源保留、自訂目標樣式及清理；E09 另確認 240 ms 完成即結束。
- 排程、鏡頭、導航及舊指標單元檢查：85 項通過。既有賦值與初始化瀏覽器檢查：7 項通過。先前已完成的語意、容器與控制檢查依有效依賴保留，不為增加數字重跑。
- JavaScript 語法與 git diff --check 通過。測試使用獨立服務及 Edge，不操作使用者分頁或私人投影片。
- 執行記錄位於被忽略的 algo-vis-backend/test-results/event-contracts/，不提交截圖、編譯產物、log。

## 明確邊界

67 案例不是全部 C++ 語法的證明；精確時鐘探針目前涵蓋 10 個賦值案例，其餘依案例要求檢查 SVG 與控制，未宣稱全部逐毫秒驗證。

舊 Trace 缺少 min/max 完整運算元時，只呈現有證據的複製並警告重新 RUN；舊容器 Trace 若不能確認中間內容，保留已儲存結果並警告，不猜造動畫。新資料、缺新欄位的舊資料、自訂值／明確關閉及保存重開由控制案例覆蓋。
