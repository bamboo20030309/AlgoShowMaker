# 快速排序飛行副本與可見來源顏色一致

## 原因

使用者回報遞迴切換時來源白色、複本綠色。隔離瀏覽器實際記錄到 `event-253` 的 pivot 宣告初始化：來源 `quick_sort:arr@76#2` 為 `#ffffff`，副本卻是 `rgba(165, 214, 167, 0.6)`，數值同為 3。

事件值與指向已使用共用執行狀態，但 `createAssignmentTransfer` 仍優先選取 previousObjects 裡的舊 SVG。上一層分區的綠色因此被帶到新一層白色來源的複本。

## 修改

- 完整格子轉移優先複製目前實際可見的來源 SVG，包含附著樣式；來源已離場才回退歷史外觀。保留來源、事件值、幾何量測與提交時序。
- 可見性核實連線狀態與祖先 display／visibility／opacity，避免把尚未顯示的來源當成目前畫面。
- 前端 tween 325、嵌入 runtime 80、slides 325。Trace 生成指紋未變，不要求重新編譯公開教材。

- `declaration-cell-copy.browser.test.js`：新編譯、已保存、重開與明確關閉通過；自訂紫色描邊以真實持久化 Studio styles 設定，核實來源與副本皆保留。舊測試只改前一幀 DOM，現改成實際保存的設定，沒有取消自訂描邊答案。
- `assignment-detached-source.browser.test.js`：連續 7／8 賦值、同值 0 複製、落地提交、2 倍／4 倍、新目標、隱藏來源數字落入、幾何回退、八皇后六個 L/R 複本與兩解皆通過。
  - 原第一項固定要求上一幀紅色，即使可見來源已明確變綠，與本次規則衝突；現獨立要求初始紅色、新來源綠色、副本等於可見來源綠色。
