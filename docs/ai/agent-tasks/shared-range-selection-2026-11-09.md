# 共用閉區間選取語法

## 使用者確認

`[:]` 作為資料區間語法，`@frame num[1:n-1]` 顯示該區段。箭頭／定位使用整段可見格子的聯集作為一個端點，不展開所有格子組合。保持原始索引，包含兩端。

## 實作範圍

- 共用 trace-selection 解析索引、閉區間、空端點及巢狀運算式；frame/object/style/語意端點/繪圖迴圈／快照使用同一套規則。
- 支援 [l:r]、[:r]、[l:]、[:]，以及矩陣 [r1:r2][c1:c2]、單列／單欄。單格 [i] 行為保留，不重新加入舊多指標語法。
- frame/object 顯示原始資料的區段；字串範圍使用字元視圖。矩陣緊密排版，同時將語意 ID、索引標籤、樣式、事件及箭頭對回原座標，未改動 C++ state。
- arrow/text/camera/place 使用區段聯集，place 支援來源與目標區段；移動的仍是所屬物件。pointer 的資料目標區段限制其可見範圍，位置仍是原索引。
- keep 可保存指定區段；silent keep 視圖優先使用當前的顯示設定，避免錯存前一個完整視圖。
- 區段超出資料只取有效格子，起點大於終點為空，維度錯誤及 [:] 與 with range 並用清楚報錯。with range 舊語法保留。
- 區間是資料選取，不是 C++ 純量運算；when/let 仍是純量運算，exit 仍是整個物件退場，尚未定義部分格子退場語意。layout 節點集合也不冒充資料陣列。
- 同步更新人類指令手冊、完整參考、教材 skill 參考及 Ace 的使用範例。
