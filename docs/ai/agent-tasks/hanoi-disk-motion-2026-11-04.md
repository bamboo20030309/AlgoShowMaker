# 河內塔圓盤位移與視覺排程等待修正

日期：2026-11-04；分支 intergration。

## 原因與修改

上一版無事件序列補排程未限制 render，disk 的空柱新增圓盤也被當作一般陣列的新格子，遮住原本跨柱位移。補排程另外排在所有真實事件之後，造成等待後續 output／call 提示。

現在補排程只適用 render normal；disk／heap 保留自己的幾何與連續身分規則。暫時畫面變化先於後續提示執行，仍保留必要的鏡頭／結構／新節點 barrier；真實事件的相對順序不變。不用改動使用者的河內塔程式。

## 驗證

- 完整河內塔測資 N=4，前三次搬盤 × 1／2 倍速，共 6 組固定時鐘檢查；盤子以穩定身分比較跨柱前後座標，90 ms 時可見且位於途中，不可消失或直接跳到終點。
- 同時驗 ans 先擴框，再讓格子與文字入場；空陣列預留一格外框尺寸不變，第二格起才增加高度。
- 關閉鏡頭探針檢查視覺操作只保留最多 180 ms 的新節點入場 barrier，不等待後續程式事件。正常使用仍保留必要鏡頭過渡。
- 一般陣列有／無事件 20 組專項通過，確認沒有破壞之前的插入與刪除順序。
- JavaScript 語法與 git diff --check 通過。所有測試用隔離服務及瀏覽器。

不合併 main，不發布 release。
