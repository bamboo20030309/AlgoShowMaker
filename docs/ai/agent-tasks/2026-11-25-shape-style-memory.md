# 圖形樣式記憶與側欄

- 箭頭頭型、實線／虛線各自保存於本機 `asm_slide_shape_preferences_v1`，重新開啟仍保留；只作新增或明確轉換圖形時的預設，不覆蓋選取的舊物件。
- 新增入口及編輯欄的箭頭／線段圖示同步記憶值；明確轉換成線段／箭頭也套用相同設定。
- 框線、填色、粗細、圓角、線型與箭頭大小／頭型集中到選取後的左側編輯欄，移除浮動圖形工具列。選色器開在側欄右側，避免遮擋設定。
- 虛線以 Fabric 原有 strokeDashArray 保存；舊自訂陣列及明確實線保留。標準虛線隨粗細調整，新偏好不回寫舊圖形。
- V1 局部驗證：3 個瀏覽器案例通過，涵蓋樣式記憶／圖示、實線虛線切換、轉換圖形、選色器及圓角、新舊物件保存重開、關閉動畫設定與箭頭像素接點。語法／差異檢查及實際截圖確認通過；未跑演算法驗證集。
