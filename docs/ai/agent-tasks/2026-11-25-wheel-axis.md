# 滾輪指定方向與介面補正

- 左鍵＋滾輪只切當段垂直頁，到邊界停住；右鍵＋滾輪切水平段，進入最上頁。底部左右箭頭也從目標段最上頁開始。
- 普通滾輪保留垂直優先順序；拖曳選取後的動畫畫布，普通滾輪仍縮放。按鍵組合明確指定切頁時優先切頁，放開按鍵不再誤觸播放快捷鍵／右鍵選單。可用於編輯與展示畫面，文字欄位、可滾動內容及對話框維持原操作。
- Table 移除格子選取、底線貼齊字元，滴管改為純圖示，仍保留提示與無障礙名稱。
