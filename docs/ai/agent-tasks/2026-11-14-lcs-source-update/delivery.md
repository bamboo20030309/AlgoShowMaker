# LCS 程式碼更新

## 範圍與結果

使用者提供新的 LCS 程式碼附件。原樣替換 algorithm_sample/DP/LCS.cpp，以及公開 LCS 投影片的建表動畫 lcs-slide-09；附件的 when 0、程式碼顯示設定、鏡頭、獨立 row/column 指標及黑色箭頭全部保留。另一段 lcs-slide-12 是專門的回溯展示，保留其程式碼與設定。

只對 lcs-teaching 執行預建：建表 82 幀、回溯 22 幀，兩份均由現行後端重新執行產生（各有 65 個獨立取大事件）。投影片檔僅保存 Trace ID，沒有內嵌完整 Trace。更新公開清單為新的不可變投影片檔與引用 ID，保留舊引用資源供舊分享連結使用。

## 驗證

- 建表投影片中的程式碼與附件／樣本檔逐字一致；沒有改動回溯版程式碼。
- 預建工具核對兩份 Trace 的內容雜湊、來源／輸入、生成指紋與程式碼座標。
- lcs-sample.test.js：改用新獨立指標及黑色箭頭的明確規格；原測資長度 5，答案 abcde、edcba，另測 ace。為維持回溯演算法驗證，只在測試用副本啟用附件明確關閉的 DFS 幀；不改公開碼的 when 0。
- lcs-axis-events.browser.test.js 使用附件原碼，核對 1→2、4→5 幀的 j 指標位置、相同字元一支黑箭頭及瀏覽器錯誤。
- V2 局部驗證；沒有執行全部演算法或完整 regression。
