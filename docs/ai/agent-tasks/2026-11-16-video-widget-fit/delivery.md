# 影片物件封面與播放器貼齊外框

## 原因與修正

唯讀查看使用者指定頁面：640×360 的影片外框與內容區一致，但封面實際只有 608×342，且 margin=20px 0。原因是 Reveal 共用圖片樣式的 max-width/max-height=95% 與上下 margin，不是影片物件本身的尺寸錯誤。

影片封面與 iframe 明確清除這些 maximum、margin、padding 及 border，維持原外框大小、位置、比例與播放設定。更新 slides.css 版本參數讓重新整理取得修正。

## 驗證

V1 局部介面驗證，未跑演算法驗證集。新增獨立隨機埠／快取及瀏覽器案例，在修正前重現上下與右側偏移；修正後封面與播放器四邊偏移均小於 0.1px。

涵蓋缺少新欄位的舊影片、新增影片、直式自訂尺寸、明確關閉 autoplay、muted/startSeconds 保留、儲存、重開與進入展示播放；無 pageerror。YouTube 網路以 fixture 攔截，只驗證本專案外框與播放器幾何，不宣稱改變 YouTube 影片本身已存在的黑邊。

使用者分頁僅讀取畫面與 DOM 尺寸，未編輯或重新載入；雲端原檔未改動。測試投影片使用獨立資料。
