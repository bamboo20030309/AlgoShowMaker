# 獨立取大／取小事件交付

## 任務定義

使用者要求 min/max 成為獨立選值操作，巢狀依內層完成再到外層的順序排事件，最後才賦值。保留先前選中格子縮放、幀尾 260ms 還原、單常數／混合常數及原有指標規則。

## 實作

- 插樁對二參數 min/max 在求值處記錄獨立事件；來源可包含巢狀選值、四則運算及更新／賦值表達式。每次來源只求值一次。內層的已選來源供外層使用，不使用幀結束值回推。
- runtime 分開記錄 select-max/select-min，父層及消費者保存依賴 ID。接收賦值保留來源追溯資料但不再包含重播選值的動作。
- 獨立選值不額外產生通用 call 事件；兩個 lvalue 的 min/max 回傳仍為選中對象的引用，參數型別須與 C++ 二參數版本一致。
- 前端增加「取大」「取小」設定；取值與賦值各有自己的順序、反白、間隔及動作計畫。選值不負責賦值移動；原幀尾縮放還原仍共同執行。
- 修正後置運算重排：不能跨過選值的參數求值邊界；相同來源範圍的兩次 i++ 是同層操作，不互相當消費者。原 push_back(num[i++]) 的先用舊值再更新行為保留。
- 舊內嵌選值 Trace 保留相容路徑；新結果標記已產生選值事件，避免重複播放。沒有新欄位的舊資料不憑空拆事件。

## 固定答案與驗證

- selection-events.integration.test.js：獨立呼叫、min/max 巢狀、初始化、嵌入四則、後置遞增、單次執行、正確來源、依賴 ID，並測試引用不被複製破壞。
- selection-events.browser.test.js：真實 SVG 與實際播放起始事件核對順序、獨立關閉、新 Trace 存檔重開，以及 i 最終畫面必須為 2。
- minmax-presentation.browser.test.js：新、舊格式的 1x/4x 抬起、選中縮放、來源相同時選擇、幀尾還原、沒有深灰粗框。
- LCS 原測資 j 指標兩段、單黑箭頭局部驗證通過。
- postfix-presentation、nested-expressions、event-semantics 局部測試：短路、內嵌寫入、呼叫、引用與條件只執行一次通過。
- 原四個選值契約拆為八個選值／賦值固定答案，總數 71。八個資料及 SVG 案例與 E17/E19 固定時鐘分輪驗證；沒有執行全部 71 個或完整 regression。
- 既有 600ms/300ms 結合選值測試已由新獨立事件及逐時尺寸測試替代，未放寬幾何斷言。
