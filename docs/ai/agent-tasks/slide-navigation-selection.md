# 切頁取消物件選取

實際觸發 Reveal `slidechanged` 時，在更新目前頁面索引前統一清除 Fabric 選取、widget 選取、structure 格子選取與浮動工具列。已快取畫布也清除選取，切回原頁不恢復舊選取框；尚未提交的格子內容先對來源頁提交。

這不是攔截方向鍵：文字或輸入框內的方向鍵仍依原有編輯行為運作，未切頁就不取消選取。其他真正切頁的入口同樣套用清理。
