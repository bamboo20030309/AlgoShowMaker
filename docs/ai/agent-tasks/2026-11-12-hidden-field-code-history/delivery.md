# 隱藏欄位更新與程式碼標記

## 線段樹60→61幀

原因是保留的欄位tspan同時作為重播地址；事件可見性只檢查元素是否存在，未依該次after值判斷hide條件。因此lazy[now]=0雖然應隱藏，仍安排一次完整賦值動畫、空文字騰位與等待。

現在在共用assign可見性檢查排除被hide隱藏的結果；效果建立入口也做同樣保護。Trace仍保留實際更新，由正向重播按原順序即時提交；不生成0的落下動畫或空欄位。不以幀末狀態提前刪掉之前仍有效的lazy值。清零後只保留tree與sets，確切文字10,=5，位置須等同目的幀穩定顯示，不保留右側空位。

## 程式碼反白

原presenter在stable重繪時重設completedEventIds，並在返回舊幀時丟掉播放紀錄。現在同幀重繪保留紀錄，以WeakMap按Trace文件、幀ID保存已開始／已完成及排程ID集合；穩定返回還原，新播放重新開始，不跨Trace混用，不寫入檔案或雲端。
