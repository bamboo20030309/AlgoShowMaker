# 範例集分類與檔名前綴

## 更動

移除 Slide_Examples，29 份投影片程式、36 份輸入併入既有英文分類；所有程式檔名內的 - 改為 _，- 僅用於程式名稱與輸入名稱的分隔。同名既有程式不覆蓋，投影片版本以 _slides 區別。API 選單直接呈現英文檔名，來源對應搬至 algorithm_sample/.slide-samples.json。

配對只看同資料夾輸入檔第一個 - 前的完整文字，與程式去除副檔名後大小寫完全相等。匯出工具、現用測試／驗證 fixture 路徑及教材引用同步更新。歷史交付記錄保留原名。

## V1 驗證

移除資料夾前逐份核對新舊 29 份程式及 36 份輸入的完整內容完全相同。匯出工具重跑後清單與內容不變。隔離瀏覽器/API 核對 36 個動畫與投影片原始碼／輸入一致、英文名稱、無投影片範例資料夾、精確前綴及大小寫配對、程式和第二組輸入載入、重新整理保留編輯內容；沒有編譯請求與 pageerror。不啟動大型動畫驗證。

長分類清單在滑鼠移向測資時曾因 hover 消失造成無法點選；程式點選後維持該程式的測資清單展開，改選其他程式才關閉上一份。以真實瀏覽器點選第二組輸入通過，不用強制點擊繞過介面。
