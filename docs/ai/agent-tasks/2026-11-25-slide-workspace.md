# 投影片外側工作區

- 原因：Fabric 四周只有固定 180px 繪製範圍；物件再往外即被裁掉，看起來像灰色背景蓋住。編輯時改依可見工作區動態擴充，非目前頁面仍維持小範圍。
- 主畫布、分層畫布與 Fabric 選取框共用範圍；縮放、平移與視窗大小變動同步更新。不改物件座標、大小、層序或投影片內容。單張點陣圖維持原有 8192 邊長／3200 萬像素上限。
- 縮圖維持投影片 1280×720，不包含外側工作區。展示模式維持投影片邊界。
- V1 五個相關案例通過：外側像素與點選、新舊物件保存重開、多元件圖層、縮放平移、高 DPI、縮圖及文字輸入。語法／差異檢查通過，不啟動演算法驗證。兩個舊測試的滑鼠定位改讀實際畫布範圍，不再寫死 180px。
