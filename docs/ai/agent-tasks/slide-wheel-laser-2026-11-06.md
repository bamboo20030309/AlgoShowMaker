# 滾輪切頁與展示雷射游標

## 操作

- 一般投影片檢視（編輯／展示）中，普通垂直滾輪先走完目前水平欄的垂直投影片，再切到下一欄第 1 頁。反向由目前欄第 1 頁回到上一欄最後一頁；首尾不循環。
- 以實際 deck 的群組頁數計算位置，直接使用既有 Reveal.slide；不使用會先播放 fragment 或沿用前次垂直位置的 next。新建、匯入及重開的頁面沿用相同規則。
- 累積 40px 等效滾動後切 1 頁，450ms 內不再切頁；過小輸入或長時間中斷後重新累積，避免觸控板慣性連跳。
- Ctrl／Command＋滾輪繼續縮放；輸入框、ACE、可捲動內容、總覽與對話框不攔截。側欄也不觸發切頁。

## 雷射游標與內嵌畫面

展示的整個 Reveal 檢視區使用固定 32px 原生 SVG 游標，中心為紅色光點，配白色輪廓、暗色外緣與淡紅光暈，深淺底皆可辨識。切回編輯或進入總覽時還原原游標，保留編輯器自身的文字、拖曳及縮放游標。

同源 algorithm-slide-frame 在每次載入時安裝相同樣式與滾輪處理。依 2026-11-07 使用者修正，動畫畫布（canvasWrapper／arraySvg）內的普通滾輪優先交給原有鏡頭縮放，不累積切頁；播放列等畫布外區域仍可切頁。Ctrl／Command 滾輪繼續交給 iframe。只處理目前頁面的 runtime，不修改動畫編輯對話框或獨立 algorithm.html。監聽 iframe load 與既有 Reveal／body 模式狀態，不監看每次 SVG 繪製。

不新增 deck／widget 設定欄位，不保存游標或滾輪暫態；既有物件位置、縮放與自訂樣式不變。這次沒有實作塗鴉或展示選取工具。

## 驗證

- slide-presentation-controls.browser.test.js：獨立靜態服務及瀏覽器，以 3／2／1 頁的三欄舊格式教材驗證正反向、首尾、節流、小滾動累積、Ctrl 縮放、可捲動區、對話框、總覽、展示／編輯切換、SVG 游標可解碼為 32×32、內嵌頁普通／Ctrl 滾輪分工、IndexedDB 儲存重開、舊文字自訂色及縮放，以及實際新增垂直頁後的順序。
- 內嵌測試使用可控的同源 fixture 模擬子頁的鏡頭輸入，不編譯或執行演算法。fixture 須高於 Fabric 的選取層，確保真實滑鼠確實進入 iframe。
- slide-viewport-zoom.browser.test.js：原滑鼠錨定縮放、畫布拖曳、即時重繪、保存重開與展示縮放通過。
- JS 語法、差異檢查。屬 V1 前端操作，未啟動動畫／演算法驗證集。
