# 遞迴參數容器的整體移動

## 原因

八皇后數字陣列解法第8→9幀，@keep 更新 sceneGeneration，下一層 dfs 的 L/M/R 也有新的參數 lifetime。外框被當作新場景物件而失去前幀位置，內部格子卻透過索引連續性保留前幀位置，造成外框與格子分開移動。

## 修正範圍

共用 recursiveRoleContinuations 確認同一函式、父子／祖先遞迴關係、同一來源變數，且目的呼叫的參數宣告已明確關閉動畫時，將完整容器視為呈現角色交接。這是畫面角色延續，不合併 C++ 參數的值與 lifetime。

已確認的 continuingKeys 同時作用於外框、名稱、格子與索引的場景連續性，避免僅資料格保留移動來源。保留 snapshot 域隔離與顯式 visual-exit 的排除；不依相同值或陣列名稱猜交接，不將一般區域變數一律接續。

## V2 局部驗證

使用者程式語意與 input=4 作 fixture，隔離 analyze/compile 及瀏覽器驗證第8→9幀與返回父層的第13→14幀。新載入與 JSON 儲存重開，1x/4x，逐時間點核對外框有中途位置，名稱、格子與索引相對外框位置一致。另跑既有 recursive-parameter-pointer.browser.test.js 確認遞迴參數指標仍在正確目標入場。

未執行完整動畫驗證集，未更新使用者未要求替換的公開八皇后遞迴程式碼。本次僅前端交接修正，不重新生成 Trace。
