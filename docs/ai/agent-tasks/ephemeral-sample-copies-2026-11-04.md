# 範例改為頁面暫存與移除黑色標籤

日期：2026-11-04；分支 intergration。

## 確認的原因

實際讀取使用者 3100/slides.html?sample=insertion-sort 的頁面，確認編輯器顯示 arr[j,j+1] 舊語法，且狀態為範例本機副本。根因是已儲存本機範例優先於官方 archive，先前只核對儲存庫未覆蓋這條載入路徑。依使用者後續決定，改為不保存範例永久副本，取消原先準備的自動指標遷移方案。未直接操作或覆寫使用者分頁資料。

## 完成行為

- 範例每次開啟／重新整理都讀官方 archive，忽略並清理該範例舊 deck 與封面草稿。
- 範例編輯、動畫 RUN、套回投影片、undo／redo、匯入及匯出仍可使用；內容只留在本頁記憶體，不寫永久 deck 草稿。
- 不依賴 unload 刪除，避免異常關閉未觸發事件而留下新副本。共用 Trace 快取保留，避免影響其他投影片。
- 範例左上黑色 access badge 從 DOM 移除；只在編輯欄顯示「僅本次開啟，重新整理後還原」。
- 工作區與分享草稿既有儲存方式保留；刪除 deck API 只刪指定 deck，不刪共享 Trace。

## 驗證

15 項通過：1 項隔離瀏覽器整合（含舊範例覆蓋、RUN、匯出保留修改、刷新還原、無持久化範例、無黑色標籤、分享仍保存），14 項儲存檢查（新增刪除範例不影響其他 deck 及 Trace）。JavaScript 語法及 git diff --check 通過。本輪為載入與儲存策略，未跑大型動畫驗證。
