# 範例投影片舊引擎相容修正

## 問題

六份公開範例投影片的封存標記為追蹤引擎 `4/1`，目前前端使用 `8/1`。`ASMDeck.decode()` 在驗證內容並進入重建流程前拒絕任何不同的引擎版本，因此縮圖與投影片本身同時無法載入。

## 修正

- 同一格式版本的舊引擎封存檔可通過解碼，動畫仍由目前引擎重新分析與編譯。
- 較新引擎與不同格式版本仍拒絕載入。
- 內容雜湊、圖片素材清單與素材雜湊驗證維持不變。
- 更新首頁及投影片頁的 `asmdeck.js` 快取版本。

## 驗證

- `asmdeck.test.js` 與 `entrypoints.test.js`：14 個案例通過，0 失敗、0 跳過。
- 新增六份內建範例封存檔逐一解碼測試。
- 隔離 Edge 實際開啟 `/?examples=1`：6 張卡片、6 張縮圖均載入。
- 隔離 Edge實際開啟 `/slides.html?sample=quick-sort`：標題更新為「快速排序 - AlgoShowMaker」、18 個投影片 section 載入，無頁面錯誤。
