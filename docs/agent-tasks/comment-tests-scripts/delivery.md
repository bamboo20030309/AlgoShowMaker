# 測試與驗證腳本註解整理

## 範圍

- 為 `algo-vis-backend/tests/**/*.js` 加入檔案級用途、執行環境、結構與維護原則。
- 在測試案例區加入一致的段落分隔，保留具名 `test(...)` 作為各項行為契約的主要說明。
- 為 `algo-vis-backend/scripts/*.js` 補上執行流程、隔離邊界、報告用途與主要階段註解。
- 補充 `cloud-content.js`、`jwt-config.js`、`slide-library.js` 的資料流與安全邊界說明。

## 註解原則

- 註解說明「為何存在、資料如何流動、哪些條件不可破壞」，不逐行翻譯 JavaScript。
- 不改函式、常數、測試資料或斷言，不改任何執行行為。
- 測試檔以案例名稱描述具體契約，避免在每個斷言旁重複相同文字。

## 驗證分級與選擇

- 層級：V0（文件化註解，沒有執行邏輯變更）
- 分類：K 與各測試所屬分類；只驗證語法與差異，不啟動演算法驗證集。
- 驗證：所有修改的 JavaScript 執行 `node --check`，並執行 `git diff --check`。
- 舊有物件相容性：不適用；本次沒有修改載入、正規化、儲存或渲染行為。
