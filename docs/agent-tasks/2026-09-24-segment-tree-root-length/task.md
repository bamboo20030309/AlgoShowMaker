# Segment Tree 根區間長度

## 目標

- Segment Tree Structure 的「長度」代表 `index(1)` 所涵蓋的葉區間長度。
- 輸入長度後，由引擎依標準 `2v`、`2v+1` 編號建立完整拓樸與必要的稀疏 storage。
- 修正範例投影片第 5、11、15 頁在 `n=10` 時缺少 storage index 24、25 的問題。

## 驗收條件

- 長度 10 顯示 19 個實際節點，storage 最大索引為 25。
- index 12 的兩個子節點為 index 24、25，分別代表 `[6]`、`[7]`。
- 舊物件若缺少新欄位，依舊有節點數推導根區間長度，載入後可直接使用新長度行為。
- `.asmdeck` 匯出資料保存根區間長度與稀疏 storage。
