# 投影片漸進載入交付紀錄

## 行為

- `.asmdeck` 完成格式與雜湊驗證後立即建立投影片介面，不再等待全部演算法動畫重建。
- 目前頁優先；之後依距離預載鄰近頁，再於背景依序完成其餘動畫。
- 使用者跳頁時會更新下一張重建工作的優先位置。
- 尚未完成的演算法頁沿用既有 placeholder，顯示背景建立狀態；完成後只更新該頁 iframe，不重建整份 deck DOM。
- 重建沿用 IndexedDB exact／base trace 快取，背景工作一次只處理一張。
- 單張重建失敗時保留程式碼、輸入、畫面設定與其他投影片，並標示需要重新 RUN。
- 本機／雲端匯入先保存可恢復的精簡 deck；全部背景重建完成後再保存完整結果並排程雲端同步。
